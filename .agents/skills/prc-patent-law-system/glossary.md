# 术语表 — 专利法 · 实施细则 · 审查指南（合并）

共 540 条（法 51 / 细则 96 / 指南 393），按术语拼音排序，拉丁字母开头的术语按字母排在对应位置。每条前的标记是来源层：【法】《专利法》2020 年修正、【细则】《实施细则》2023 年修订、【指南】《审查指南》2023 年版。同一术语在不同层各有定义时相邻排列，便于对照三层的表述。

格式：【层】**术语** — 定义（章节号 条号/节号）。章节号对应 `chapters/` 下的文件：`law-chNN` 专利法、`reg-chNN` 实施细则、`gl-pN-chNN` 审查指南第 N 部分第 NN 章。条号写法：法条按原文（第N条）；细则条号为 2023 年修订后的编号；指南用章内节号。法层词条后的"（通称）"表示法条未直接使用该词。


## 0-9

【细则】**1个月补充期** — 自提出无效请求之日起可增加理由、补充证据的窗口（reg-ch04 细则第71条）

## A

【指南】**案卷** — 案卷夹（兼记录案卷重要内容）及夹内各种文件的总称，以申请号为案卷号（gl-p5-ch04 第2、2.1、2.3节）
【细则】**案卷保存期** — 自失效之日起算，失效申请案卷2年、失效专利权案卷3年（reg-ch13 细则第145条第2、3款）
【细则】**案卷查阅复制** — 对已公布或公告案卷和登记簿的公众访问，以局同意为前提（reg-ch13 细则第145条；法第21条）

## B

【指南】**办理登记手续通知书** — 与授权通知同时发出，申请人须自收到日起2个月内缴纳授权当年年费的通知（gl-p5-ch09 第1.1.2、1.1.3节）
【细则】**保藏证明与存活证明** — 认可保藏单位出具、申请日起4个月内须交的两份文件（细则第27条第（一）项）（reg-ch02）
【指南】**保密基准** — 判断是否需保密的尺度，按国家有关规定执行（gl-p5-ch05 第2节）
【法】**保密审查** — 在中国完成的发明或实用新型向外国申请专利前，须报经国务院专利行政部门审查；违反则在中国不授权（第19条，law-ch01）
【指南】**保密审批通知书** — 告知申请人予以或不予保密的通知（gl-p5-ch05 第3.1.2节）
【指南】**保密原则** — 决定前合议组不得向一方透露观点、原则上不单方会晤（gl-p4-ch03 第2.3节）
【指南】**保密责任（文档）** — 公布/公告前专利局对申请内容负有的不得对外提供义务（gl-p5-ch04 第5.1节(1)，法21.3）
【指南】**保密证明材料** — 有定密权限的机关、单位出具并盖章的定密文件，已定密者请求保密时必须提交（gl-p5-ch05 第3.1.1节）
【细则】**保密专利申请** — 涉国防以外国家安全或重大利益的申请；涉国防利益的为国防专利（reg-ch01 细则第7条）
【指南】**保密专利申请** — 涉及国防利益以外的国家安全或重大利益、经专利局确定按保密程序审批的发明或实用新型申请（gl-p5-ch05 第1节，细则7.2）
【指南】**被控侵权人** — 收到专利权人律师函、电商平台投诉通知书等的单位或个人（gl-p5-ch10 第2.1节）
【法】**本国优先权** — 在中国首次申请后12个月（发明/实用新型）或6个月（外观设计）内再就相同主题申请所享有的优先权（第29条第2款，law-ch03）
【指南】**辩论终结** — 合议组宣布辩论结束、进入最后意见陈述的节点，也是公知常识性证据等补证的截止点（gl-p4-ch04 第5.3节）
【指南】**表格部分** — 记载检索领域、数据库、对比文件及其相关程度的报告组成部分（gl-p5-ch10 第4.1.1节）
【指南】**并列独立权利要求** — 第一独权之外的其他独权，包括引用在前独权的独权（gl-p2-ch02 第3.1.2节）
【指南】**病与证** — 中医辨证论治下同一病有不同证型、同一证型可见于不同病，与西医病不完全对应（gl-p2-ch11 第4.2节）
【指南】**必然趋势** — 现有技术已指出的效果变化规律，沿其得到的改进不构成创造性（gl-p2-ch10 第6.1节）
【细则】**必要技术特征** — 独立权利要求为解决技术问题必须记载的特征（reg-ch02 细则第23条第2款）
【指南】**必要技术特征** — 解决技术问题不可缺少、总和足以构成技术方案并区别于背景技术的特征（gl-p2-ch02 第3.1.2节）
【指南】**驳回决定所依据的理由和证据** — 复审合议审查的默认范围（gl-p4-ch02 第4.1节）
【指南】**驳回请求** — 已受理案件经审查认定不符合受理条件时作出的程序性决定（gl-p4-ch01 第7.6节）
【指南】**驳回通知** — 向国际局发出、载明全部理由与法律条款的否定意见，是申请人答复的起点，不同于驳回决定（gl-p6-ch02 第3.2节）
【法】**Bolar 例外**（通称）— 为提供行政审批所需信息而制造、使用、进口专利药品或专利医疗器械，不视为侵权（第75条第(五)项，law-ch07）
【指南】**不必检索的主题** — 客体不符、法5/25、无实用性、不能实现（实用新型）或图片照片不清（外观设计）（gl-p5-ch10 第3.3节）
【指南】**补充检索** — 权利要求修改、澄清、审查意见改变或原检索不完整时为获得更合适对比文件而进行的再次检索（gl-p2-ch07 第11节）
【细则】**不得扩大原专利的保护范围** — 无效中修改权利要求的唯一实体边界（reg-ch04 细则第73条第1款）
【指南】**部分无效** — 部分权利要求或部分产品/项无效、其余维持且视为自始存在（gl-p4-ch03 第5节）
【指南】**部分优先权** — 在后申请中仅部分方案享有首次申请优先权日，其余以在后申请日为申请日（gl-p2-ch03 第4.1.4节）
【指南】**部分优先权 / 多项优先权（核实）** — 逐项权利要求认定优先权日；组合多件在先申请特征的权利要求不享有（gl-p2-ch08 第4.6.2节）
【细则】**不合理延迟的实际天数** — 起算日至公告授权日的间隔天数扣除两类延迟后的净数，即补偿天数（reg-ch05 细则第78条第2款）
【指南】**不合理延迟（法42.2）** — 起算日至授权公告日的间隔天数扣除合理延迟和申请人引起延迟后的补偿天数（gl-p5-ch09 第2.2节）
【指南】**补交实验数据** — 申请日后补交的数据应予审查，所证明效果须能从原申请公开内容中得到（gl-p2-ch10 第3.5.1节）
【指南】**补交遗漏文件通知书** — 仅对要求了优先权的缺件发明/实用新型申请发出，触发两个月补交期（gl-p5-ch03 第2.3.3节）
【指南】**不可恢复的四类期限** — 宽限期、优先权期限、专利权期限、侵权诉讼时效（gl-p5-ch07 第6.1节，细则6.5）
【细则】**不可抗拒的事由** — 触发"障碍消除2个月内且届满2年内"恢复窗口、无需缴费（reg-ch01 细则第6条第1款）
【指南】**不丧失新颖性的声明与证明（外观设计国际申请）** — 法24(2)(3)情形须提出国际申请时声明并在国际公布起2个月内提交证明；法24(1)(4)情形由专利局指定期限（gl-p6-ch02 第6.3节，细则140、33.4）
【指南】**不丧失新颖性宽限期（初审手续）** — 申请日前6个月内四种公开不损新颖性，须申请时声明并2个月内举证（gl-p1-ch01 第6.3节）
【细则】**不予受理** — 缺最低文件、非中文、格式不合、缺名称或地址、明显违反法第17/18条、类别不明（reg-ch03 细则第44条）
【指南】**不再传送登记本和检索本的通知书** — 国际申请需保密时终止国际阶段的通知（gl-p5-ch05 第6.3.2节）
【指南】**补正通知书** — 针对可补正缺陷，指明缺陷、理由、期限；同一缺陷发过两次仍未消除即可驳回（gl-p1-ch01 第3.2、3.5节）

## C

【指南】**材料特征和方法特征** — 实用新型权利要求中的非形状构造特征，新颖性与创造性审查中均应予考虑（gl-p4-ch06 第3、4节）
【指南】**参数或制法表征的产品** — 结构不明产品的表征方式，无法与现有产品比较即推定无新颖性（gl-p2-ch10 第4.3、5.3节）
【指南】**产品的构造** — 各组成部分的安排、组织和相互关系，分机械构造与线路构造，复合层属构造（gl-p1-ch02 第6.2.2节）
【指南】**产品的形状** — 可从外部观察到的确定的空间形状，含三维形态与二维断面（gl-p1-ch02 第6.2.1节）
【指南】**产品（实用新型）** — 经产业方法制造、有确定形状、构造且占据一定空间的实体（gl-p1-ch02 第6.1节，法2.3）
【细则】**产权激励** — 股权、期权、分红等分享创新收益的方式（reg-ch07 细则第92条第1款；法第15条第2款）
【指南】**产业** — 工业、农业、林业、水产业、畜牧业、交通运输业及文化体育、生活用品、医疗器械等行业（gl-p2-ch05 第2节）
【指南】**超出原图片或照片表示的范围** — 修改后的设计与原始文件相应设计属于不相同的设计（gl-p1-ch03 第10节，法33）
【指南】**撤回开放许可声明请求** — 撤回声明的书面请求，不得附条件，自公告之日起生效（gl-p5-ch11 第4节，法50.2）
【法】**惩罚性赔偿**（通称）— 故意侵权且情节严重时，在损失/获利/许可费倍数确定数额的1倍以上5倍以下确定赔偿（第71条第1款，law-ch07）
【指南】**成品率低** — 能重复实施、仅因技术条件未确保而产出低，与无再现性有本质区别（gl-p2-ch05 第3.2.1节）
【指南】**成套产品** — 同一大类、各自独立、设计构思相同、各有独立使用价值且组合有组合使用价值的两件以上产品（gl-p1-ch03 第9.2节，法31.2）
【指南】**程序节约原则** — 一通尽量列出全部问题以减少通信次数，但不得因此违反请求与听证原则（gl-p2-ch08 第2.2节）
【指南】**程序节约原则（初审）** — 一次通知书指出全部缺陷；缺陷均可依职权修改克服的可不发补正通知书（gl-p1-ch02 第2节）
【指南】**程序模块构架** — 与程序流程步骤一一对应的装置权利要求的法定解读，非硬件实体装置（gl-p2-ch09 第5.2节）
【细则】**撤销原驳回决定、继续审查** — 复审的肯定性结果，回到审查程序而非直接授权（reg-ch04 细则第67条第2款）
【指南】**充分公开** — 说明书清楚、完整达到本领域技术人员能够实现的程度（gl-p2-ch02 第2.1节，法26.3）
【指南】**重新确定申请日（实用新型）** — 补交说明书缺少的附图时以补交日为申请日（gl-p1-ch02 第7.2节，细则46）
【指南】**重新确定申请日通知书** — 补交附图、援引内容超出副本、分案原申请日改正时以补交日重定申请日（gl-p1-ch01 第4.2、4.7、5.1.1节）
【法】**创造性** — 发明：与现有技术相比有突出的实质性特点和显著的进步；实用新型：有实质性特点和进步（第22条第3款，law-ch02）
【指南】**创造性** — 与现有技术相比具有突出的实质性特点和显著的进步（gl-p2-ch04 第2节，法22.3）
【指南】**传送条件** — 专利局向国际局转送申请须同时满足的七项要件，缺一不传送并发不传送通知书（gl-p6-ch01 第2.2.2、2.3.3节）
【指南】**出版物** — 记载技术或设计内容、独立存在且能证明公开时间的传播载体（gl-p2-ch03 第2.1.2.1节）
【指南】**初步检索 / 常规检索 / 扩展检索** — 依次推进的三阶段检索过程（gl-p2-ch07 第6.2节）
【法】**初步审查** — 所有专利申请都经过的审查；实用新型和外观设计经初步审查无驳回理由即授权（第34、40条，law-ch04）
【细则】**初步审查** — 文件齐备与格式审查，加按类别列举的明显缺陷审查（reg-ch03 细则第50条）
【指南】**初步审查合格通知书** — 申请文件合规且无明显实质性缺陷时发出，指明公布所依据的文本（gl-p1-ch01 第3.1节）
【指南】**处分决定** — 因耽误期限作出的丧权决定：视为撤回、视为放弃、终止、不予受理、视为未提出/未要求优先权（gl-p5-ch07 第5.2节）
【法】**从属专利**（通称）— 实施有赖于在先专利的后一专利；可互相申请强制许可（第56条，law-ch06）
【细则】**从优发给** — 建议被采纳而完成的发明创造，奖金高于一般标准（reg-ch07 细则第93条第2款）

## D

【细则】**代表人** — 2人以上申请人未委托代理时，除另有声明外的第一申请人（reg-ch02 细则第17条第3款）
【指南】**代表人** — 多个当事人未委托代理时，请求书中声明指定的非第一署名当事人，作为收件人（gl-p5-ch06 第2.2.1节）
【指南】**单独对比** — 每项权利要求只与一份对比文件中的一项技术方案比较，不作组合（gl-p2-ch03 第3.1节）
【指南】**单独对比（外观设计）** — 以一项对比设计与涉案专利比较，不得结合两项以上（gl-p4-ch05 第5.2.1节）
【指南】**单独指定费** — 国际局收取后转交专利局的指定中国费用，专利局不退费（gl-p6-ch01 第4.1节）
【指南】**当事人处置原则** — 请求人可放弃范围/理由/证据，双方可和解，专利权人缩小或放弃视为承认（gl-p4-ch03 第2.2节）
【细则】**单行本** — 按件出版的全文文件，分发明申请单行本与三类专利单行本（reg-ch09 细则第108条）
【指南】**单行本** — 与公报同日出版的单件专利文献，文献种类代码A、B、U、S（gl-p5-ch08 第2.1–2.2节）
【指南】**单一性** — 一件申请限于一项发明，或属于一个总的发明构思的两项以上发明（gl-p2-ch06 第2.1.1节，法31.1）
【指南】**单一性恢复费** — 国际单位单一性结论正确时，为保留未经国际检索的发明须在通知后2个月内缴纳的费用，不缴视为撤回该部分且不得分案（gl-p3-ch02 第5.5节，细则133.2）
【指南】**等同特征** — 以基本相同手段实现基本相同功能达到基本相同效果、且本领域技术人员能联想到的特征（gl-p2-ch07 第5.4.2节）
【指南】**电子等排体置换** — NH2/CH3、-O-/-NH- 等经典等排体替换通常有动机，仅在效果预料不到时有创造性（gl-p2-ch10 第6.1节）
【指南】**电子公报** — 在国家知识产权局政府网站公布的公报形式（gl-p5-ch08 第1.1节）
【指南】**电子文档** — 基于纸件制作或当事人电子提交、连同法律状态与著录项目历史等形成的电子记录集合（gl-p5-ch04 第3节）
【细则】**电子形式** — 可有形表现、可随时调取的数据电文，视为书面形式（reg-ch01 细则第2条）
【法】**抵触申请**（通称）— 他人在申请日以前就同样发明创造提出、在申请日以后公布/公告的申请，破坏新颖性（第22条第2款、第23条第1款，law-ch02）
【指南】**抵触申请** — 任何单位或个人就同样的发明或实用新型在申请日前提出、申请日后（含当日）公布或公告的申请，仅损害新颖性（gl-p2-ch03 第2.2节，法22.2）
【细则】**递交日** — 邮寄以邮戳日、电子提交以进入指定系统日为准（reg-ch01 细则第4条第1、2款）
【指南】**递交日** — 申请后其他文件的到达日，参照申请日规则确定，可凭回执或邮局证明更正（gl-p5-ch03 第3.2、4节）
【指南】**第一发言人** — 一方多人参加口审时指定的作主要发言的人（gl-p4-ch04 第3节）
