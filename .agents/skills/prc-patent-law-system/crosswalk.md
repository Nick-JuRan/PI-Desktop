# 条文对照 — 专利法 ↔ 实施细则 ↔ 审查指南

把三层按条文串起来：第一表以专利法条文为主键，给出该条所在的专利法章节，以及引用了该条的实施细则章节和审查指南章节；第二表以实施细则条文为主键，给出其所在章节和引用它的审查指南章节。

"引用"关系由各章节文件里的引注（`法N`、`法第N条`、`细则N`、`细则第N条`，含区间与顿号列举）自动汇总，只反映章节文件写了什么，不是法规之间的全部对应关系，也可能有漏；"—" 表示没有章节引用该条。章节 ID（`law-chNN` / `reg-chNN` / `gl-pN-chNN`）对应 `chapters/` 下同名开头的文件。

用法：被问到"第 N 条"时，先在这里定位章节，再读章节文件；法条本身的规定读 law- 章节，程序与期限读 reg- 章节，审查标准读 gl- 章节。
