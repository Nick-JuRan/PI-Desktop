# 中国专利法规三层合一：专利法 · 实施细则 · 审查指南
**来源**：《专利法》2020 年修正（8 章 82 条）｜《专利法实施细则》2023 年修订（13 章 149 条）｜《专利审查指南》2023 年版（6 部分 38 章）｜**章节文件**：59｜**生成日期**：2026-10-15（三个单文本技能合并）

## 如何使用本技能

一个问题通常要把三层拼起来：**法**定规则 → **细则**定程序与期限 → **指南**定审查员的判断标准。

| 问题形态 | 先读 | 再对照 |
|---|---|---|
| "第 N 条怎么规定"；客体、归属、保护范围、侵权、赔偿 | `law-chNN` | [crosswalk.md](crosswalk.md)：引用该条的细则/指南章节 |
| "程序上怎么办、期限多长、逾期后果是什么" | `reg-chNN` | `gl-p5-*`（事务处理）、对应 `law-` 条文 |
| "审查员按什么标准判"；怎么答复、怎么修改 | `gl-pN-chNN` | `reg-ch03`（修改时机、驳回理由）、`reg-ch04`（复审无效程序） |
| 一个术语在三层分别怎么定义 | [glossary.md](glossary.md)（同名词条相邻） | — |

- **章节 ID**：`law-chNN` 专利法第 NN 章，`reg-chNN` 细则第 NN 章，`gl-pN-chNN` 指南第 N 部分第 NN 章；文件 = `chapters/<ID>-<标题>.md`，开头标明来源层，每条规则后标注出处（法22.3 = 专利法第 22 条第 3 款；细则57.3 = 细则第 57 条第 3 款，2023 年编号；第3.2.1节 = 指南章内节号），文末「关联」列出另两层的对应章节。
- **带主题** → 下方主题索引，查不到再看 [index.md](index.md)；**带条文号** → [crosswalk.md](crosswalk.md)；**带章节 ID** → 直接读；**浏览** → index.md 章节索引。
- 回答时引用法条、细则条号或指南节号，并提示以官方文本和专业意见为准。

## 三层核心规则（按专利生命周期）

**客体与三性** — 法2 三类客体（有"方法"只能走发明；外观设计含局部）；法5/法25 排除 → 指南两道门：先法25（智力活动规则看"仅仅涉及"，诊断方法看"活体 + 直接结论"），再法2.2 三要素（技术问题、技术手段、技术效果）（gl-p2-ch01；算法类见 gl-p2-ch09）。法22 三性以申请日为界：新颖性单独对比，抵触申请只损新颖性，数值范围落入/共同端点/重叠 → 无新颖性（gl-p2-ch03）；创造性三步法：最接近的现有技术 → 区别特征与实际解决的技术问题 → 整体是否给出"作用相同"的技术启示，"预料不到的技术效果"是分水岭（gl-p2-ch04）；实用性先审（gl-p2-ch05）。法23 外观设计三关 → 无效中以"一般消费者、整体观察综合判断"（gl-p4-ch05）。

**归属与涉外** — 法6/8 归属三步（执行单位任务或主要利用单位资源 → 单位）；细则12 职务发明含离职 1 年内；奖酬约定优先，兜底奖金发明 ≥4000 元、实用新型/外观设计 ≥1500 元（细则92–94）。法19 在中国完成的发明/实用新型出境前保密审查 → 细则7–9 三路径（gl-p5-ch05）；无居所外国主体须委托代理（法18）。

**申请、优先权、宽限期** — 法26/33 说明书是存款、权利要求是取款，修改不超原记载 → 细则17–26 文件格式（独权前序 + 特征、多项从属择一引用）→ 清楚、完整、能够实现与支持（gl-p2-ch02）。法29/30 优先权 12/6 个月、副本 16/3 个月 → 细则34–37 声明三要素限期补正、恢复 2 个月、增改 16/4 个月（gl-p1-ch01）。法24 宽限期 6 个月四种公开 → 细则33 申请时声明 + 2 个月证明，缺一不适用。法31 单一性 = 相同或相应的特定技术特征（细则39，gl-p2-ch06）。

**受理、审查、授权** — 细则42–46 受理看最低文件集、六种不予受理、援引加入 2 个月（gl-p5-ch03）；法9 同日双报须声明、授权前放弃实用新型（细则47）；分案最迟在登记手续期限届满前，驳回/撤回后不得（细则48–49，gl-p2-ch06）。法34–37 时间线：18 个月公布 → 3 年内请求实审 → 一通 4 个月/再通 2 个月答复，逾期均视为撤回；主动修改窗口见细则57；答复中的修改须针对缺陷且不超范围，扩大独权、换主题、加权利要求不接受（gl-p2-ch08）；驳回只能引细则59 清单且已听证。授权通知起 2 个月办登记，否则视为放弃（细则60，gl-p5-ch09）。

**复审与无效** — 法41 驳回后 3 个月复审 → 3 个月起诉；复审修改仅限消除驳回缺陷（细则66，gl-p4-ch02）。法45–47 任何人可请求无效：理由限细则69 清单且须具体说明，一事不再理；请求日起 1 个月补充理由证据（细则71）；专利权人只做"减法"（删权利要求、删方案、进一步限定、改明显错误，细则73，gl-p4-ch03）；请求人不回执且不出席口审 → 视为撤回（细则74，gl-p4-ch04）；证据规则见 gl-p4-ch08。无效自始不存在，已执行判决、已履行合同不追溯（法47）。

**期限、送达、恢复、费用** — 细则4 递交日看邮戳/进入系统日，送达自发文日满 15 日推定、公告满 1 个月（gl-p5-ch06）。细则6 两条恢复路径：不可抗拒事由（障碍消除起 2 个月且届满起 2 年内）、正当理由（收到通知起 2 个月 + 恢复费）；宽限期、优先权期限、专利权期限、诉讼时效不可恢复；法定期限不可延长，指定期限一般 2 个月、届满前可按月缴费延长（gl-p5-ch07）。年费滞纳期 6 个月、每超 1 个月加 5%，期满未缴自应缴日终止（细则110–117，gl-p5-ch02）。

**保护期、补偿、终止** — 法42 保护期 20/10/15 年自申请日起；两类补偿都要请求：授权延迟（申请满 4 年且实审请求满 3 年后授权）公告起 3 个月请求，双报换取的发明不补（细则77–79）；新药上市许可起 3 个月请求，≤5 年且总有效期 ≤14 年（细则80–84，gl-p5-ch09）。法43–44 不缴年费或书面放弃 → 提前终止。

**许可** — 法50–52 开放许可 = 挂牌定价：授权公告后声明 + 公告费率，实用新型/外观设计须附专利权评价报告（2 个月出具、一专利一份，细则62–63，gl-p5-ch10），禁止情形与备案见细则85–88、gl-p5-ch11。法53–63 强制许可仅发明和实用新型：五事由（不实施——授权满 3 年且申请满 4 年、垄断、紧急状态/公共利益、公共健康药品出口、从属专利）、三限制（半导体、主要供国内市场、先以合理条件请求许可未果）；使用费裁决 3 个月（细则89–91）。

**保护与维权** — 法64 保护范围以权利要求为准。法65/72/73 双轨：行政处理可责令停止，法院管赔偿，诉前可行为/财产/证据保全；无效请求被受理后可请求中止处理（细则95–98）。法71 赔偿阶梯：实际损失或侵权获利 → 许可费倍数 → 法定 3 万–500 万；故意且情节严重 1–5 倍惩罚性赔偿；对方藏账簿可按权利人主张判。被告四张牌：现有技术抗辩（法67）、五种不视为侵权（法75）、合法来源只免赔不免停（法77）、3 年时效（法74）。假冒专利五种情形，善意销售者仅责令停止（法68，细则101）；法76 药品专利链接。

**国际申请** — PCT：国际申请日即中国申请日；优先权日起 30 个月进入、32 个月付宽限费，中文声明 + 缴费 + 译文齐备才有进入日，逾期效力终止且不能依细则6 恢复；ISR/IPRP 仅参考，法33 以原始国际申请文件为准（细则118–135，gl-p3-ch01/02）。海牙：国际注册日 = 申请日，国际公布后审明显实质性缺陷；优先权副本 3 个月、宽限期证明 2 个月、分案 2 个月均自公布起算（细则136–144，gl-p6-ch01/02）。
