# 程序模式 — 专利法 · 实施细则 · 审查指南（合并）

共 43 个模式（法 13 / 细则 14 / 指南 16），按程序阶段分为十组；同一阶段里法、细则、指南三层的模式相邻，读的时候先看【法】定规则，再看【细则】走程序，最后看【指南】按审查员的标准自检。每个模式：何时用 / 怎么做 / 取舍。章节号 `law-chNN` / `reg-chNN` / `gl-pN-chNN` 对应 `chapters/` 下文件；条号：第N条或法N = 专利法，细则N = 实施细则（2023 年编号），第x.y节 = 指南章内节号。

## 一、申请路线与客体

### 【法】选择专利类型
**何时用**：有了技术方案或产品外观，决定申请路线。
**怎么做**：涉及方法 → 发明；只改产品形状/构造且想快速授权 → 实用新型（无实审，10年）；卖点是外观（含局部）→ 外观设计（15年）。方案同时满足发明与实用新型条件 → 见下一模式。（第2、22、23、40、42条）
**取舍**：发明保护期长、稳定但审批慢；实用新型快但创造性门槛低、稳定性弱，维权常需专利权评价报告。

### 【法】同日双申请
**何时用**：希望尽早获得保护，又想拿到20年发明专利。
**怎么做**：同一申请人同日对同样的发明创造既申请实用新型又申请发明；实用新型先授权；发明授权时，若实用新型尚未终止且申请人声明放弃实用新型 → 授予发明专利权。（第9条第1款）
**取舍**：只能保留一项；需在申请时同日提交，不能事后补。

### 【细则】双报与分案决策
**何时用**：同一发明创造想同时拿实用新型和发明，或一件申请含多项发明（reg-ch03 第47–49条）。
**怎么做**：双报须在申请时分别声明，发明授权前放弃实用新型，不放弃 → 驳回，不答复 → 视为撤回；分案最迟在办理登记手续期限届满前提出，不改类别、不超范围，驳回/撤回/视为撤回后不得分案。
**取舍**：双报换取的发明不享受授权延迟期限补偿（第78条）。

### 【指南】客体两道门（法25 → 法2.2）
**何时用**：涉及算法、商业方法、游戏规则、诊疗、软件的权利要求（gl-p2-ch01、gl-p2-ch09）。
**怎么做**：① 除主题名称外全是智力活动规则 → 法25.1(2) 排除；② 含任一技术特征 → 核对技术问题、遵循自然规律的技术手段、技术效果；③ 通过后再审三性。
**取舍**：客体结论看整体方案的技术性，不能只看主题名称。

### 【指南】单一性三步判断
**何时用**：多项独立权利要求，或权1 被否定后（gl-p2-ch06 第2.2.2节）。
**怎么做**：① 定第一项发明的特定技术特征（对现有技术作出贡献者）；② 找第二项有无相同或相应的特定技术特征；③ 无则通知修改，是否分案由申请人决定。
**取舍**：共有特征已知或惯用 → 不是特定技术特征；形式从属实质独立的按独权判断。

## 二、申请文件、手续与保密审查

### 【细则】申请文件格式自检
**何时用**：递交前或答复初审补正前（reg-ch02 第17–26条）。
**怎么做**：请求书九项齐全；说明书五段带标题；独立权利要求前序 + 特征部分、从属在后、多项从属择一引用；名称、术语、附图标记三对一致；摘要不超字数、指定摘要附图；不用引用语、插图（说明书）与宣传语。
**取舍**：格式缺陷可补正，但补正不能超出原记载（法第33条）。

### 【细则】生物材料与遗传资源手续
**何时用**：说明书涉及公众不能得到的生物材料，或发明依赖遗传资源（reg-ch02 第27–29条）。
**怎么做**：保藏不晚于申请日/优先权日 → 请求书与说明书写明保藏信息 → 申请日起4个月内交保藏证明和存活证明 → 遗传资源说明直接来源和原始来源。
**取舍**：逾期视为未提交保藏，直接影响充分公开；补正窗口同为4个月。

### 【细则】受理与申请日确定
**何时用**：判断某件申请何时算"提出"（reg-ch03 第43–46条）。
**怎么做**：最低文件集到齐才受理（实用新型须含附图）；六种情形不予受理；已要求优先权的发明/实用新型缺件可在递交日起2个月内援引在先申请补交并保留申请日；补交附图则申请日改为补交日。
**取舍**：援引加入只救"漏交"，不救"写错"；外观设计缺图无援引路径。

### 【法】涉外申请合规
**何时用**：外国主体来华申请，或中国完成的发明要出境申请。
**怎么做**：外国主体（在中国无经常居所/营业所）必须委托依法设立的专利代理机构；中国完成的发明/实用新型向外国或提出国际申请前先报保密审查；向外国人转让申请权/专利权依法办手续。（第10、18、19条）
**取舍**：跳过保密审查的后果是中国不授权并可能追责。

### 【细则】保密审查三路径
**何时用**：在中国完成的发明或实用新型准备向外国申请（reg-ch01 第8、9条）。
**怎么做**：直接请求保密审查（附技术方案说明）/ 先在中国申请再请求 / 向专利局提交 PCT 国际申请视为同时请求；等专利局初步意见（2个月，可延2个月）与需保密时的决定（4个月，可延2个月）。
**取舍**：涉国防利益的转国防专利机构；未经审查即出境的在中国不授权（法第19条）。

## 三、优先权与宽限期

### 【法】主张优先权
**何时用**：已在外国或中国有首次申请，想把申请日前移。
**怎么做**：发明/实用新型在首次申请日起12个月内、外观设计6个月内就相同主题申请；申请时书面声明；发明/实用新型在首次申请日起16个月内交首次申请文件副本，外观设计在3个月内交副本。（第29、30条）
**取舍**：逾期或未声明视为未要求；只覆盖"相同主题"。

### 【细则】优先权手续核对
**何时用**：要求外国或本国优先权（reg-ch02 第30–37条）。
**怎么做**：申请时声明三要素（日期、申请号、受理机构）→ 副本按期提交 → 申请人不一致附转让证明 → 漏写错写限期补正，逾期视为未要求 → 本国优先权使在先申请视为撤回 → 需恢复的在2个月内请求，增加或改正在优先权日起16个月或申请日起4个月内。
**取舍**：以外观设计为基础不能作发明/实用新型的本国优先权基础；优先权期限本身不可恢复（第6条）。

### 【法】利用新颖性宽限期
**何时用**：申请前已发生公开，评估是否还能申请。
**怎么做**：核对公开是否属于第24条四种情形（紧急状态公共利益首次公开；中国政府主办/承认的国际展览会首次展出；规定的学术/技术会议首次发表；他人未经同意泄露），且距申请日不超过六个月。
**取舍**：只是不算现有技术，不产生在先日期；其他任何公开（官网、电商、论文预印本）都不在内。

## 四、审查标准与答复（三性、修改、领域专章）

### 【法】推进发明审批
**何时用**：发明申请提交后。
**怎么做**：需要尽早公布（触发临时保护）→ 请求早日公布；在申请日起3年内请求实审并提交参考资料；外国审查结果按要求期限提交；每份审查意见在指定期限内陈述意见或修改（修改不超原始记载范围）；驳回 → 3个月内复审 → 3个月内起诉。（第13、33–41条）
**取舍**：三处逾期都视为撤回，无自动延期。

### 【细则】修改时机窗口
**何时用**：想主动修改申请文件（reg-ch03 第57条；reg-ch04 第66、73条）。
**怎么做**：发明——提实审请求时及收到进入实审通知起3个月内；实用新型/外观设计——申请日起2个月内；答复通知书时只能针对指出的缺陷；复审只能消除驳回缺陷；无效只能缩小权利要求。
**取舍**：窗口外的修改不接受，即使不超范围。

### 【指南】修改三步审查
**何时用**：实审答复、复审、无效阶段收到修改文本（gl-p2-ch08 第5.2节、gl-p4-ch02、gl-p4-ch03）。
**怎么做**：① 法33——能否从原说明书和权利要求书直接地、毫无疑义地确定；② 阶段限制——实审须针对通知书缺陷（细则57.3），复审仅限消除驳回缺陷（细则66），无效只做减法（删权利要求、删方案、进一步限定、改明显错误）；③ 是否克服缺陷且未引入新缺陷。
**取舍**：不超范围也可能不接受（扩大独权、换主题、加权利要求）。

### 【指南】新颖性单独对比 + 数值范围核对
**何时用**：任何新颖性评价，尤其含数值范围、性能/用途/制法特征的权利要求（gl-p2-ch03）。
**怎么做**：一项权利要求只对一份对比文件的一个方案；先判"同样的发明"四要素；数值范围——落入、共同端点、重叠 → 无新颖性，完全落在对比范围内且无共同端点 → 有；性能/用途/制法特征未隐含结构差异 → 推定相同，申请人举证。
**取舍**：抵触申请只用于新颖性；法9 只在同日且保护范围相同时用。

### 【指南】三步法评价创造性
**何时用**：发明的创造性审查或答复（gl-p2-ch04 第3.2.1.1节）。
**怎么做**：① 最接近的现有技术（领域相同、问题/效果最接近、公开特征最多）；② 区别特征 → 按其效果重定"实际解决的技术问题"，不得写入区别特征或其指引；③ 现有技术整体有无把区别特征用于最接近现有技术的启示——公知常识、同一文件他处、另一文件，且作用相同。
**取舍**：可组合多份文件，抵触申请不能用；站回申请日防事后诸葛亮；预料不到的技术效果可直接翻盘。

### 【指南】检索三阶段与中止
**何时用**：实审检索、评价报告检索（gl-p2-ch07、gl-p5-ch10）。
**怎么做**：定基本检索要素（领域、问题、手段、效果）→ 初步、常规、扩展 → 独权命中后仍查从权（附加特征为公知常识除外）→ 一无所获须覆盖最低限度数据库才可中止 → 报告以 X/Y/A/E/P 标注。
**取舍**：成本相称可中止，抵触申请检索须持续到 18 个月公布窗口关闭。

### 【指南】补交实验数据审查（化学）
**何时用**：申请人补交申请日后的数据证明公开充分或创造性（gl-p2-ch10 第3.5节）。
**怎么做**：先核对原申请是否已公开该效果；能从公开内容得到的才采信，再纳入法26.3 或创造性分析。
**取舍**：数据必须审查，但不能补入原申请没有的效果。

### 【指南】中药组合物主药判别法
**何时用**：中药复方的创造性（gl-p2-ch11 第5节）。
**怎么做**：按理法方药选最接近现有技术；主药不变 → 加减方（药味增减/替换/药量加减，查启示与预料不到的效果）；主药改变或无基础方 → 自组方（查方解、实验数据、配伍启示）；合方看是否仅为各方效果加和。
**取舍**：疗效可由治法治则和药味功效预测时，缺实验数据不得直接认定公开不充分。

## 五、期限、费用与权利恢复

### 【细则】期限计算与恢复决策
**何时用**：任何"是否逾期、还能不能救"的问题（reg-ch01 第4–6条）。
**怎么做**：① 定起算日——递交日看邮戳/进入系统日，送达日看发文满15日推定、交付日或公告满1个月；② 起算日不计入，按相应日届满，逢休假日顺延；③ 未届满的指定期限可请求延长（须在届满前）；④ 已耽误：先排除四类不可恢复期限（宽限期、优先权期限、专利权期限、诉讼时效），再走不可抗拒事由（障碍消除起2个月且届满起2年内）或正当理由（收到通知起2个月 + 恢复费），同时补办手续。
**取舍**：法定期限不可延长；国际申请的效力终止多数不能依第6条恢复（第122条）。

### 【指南】期限计算与权利恢复
**何时用**：任何"逾期"问题（gl-p5-ch06、gl-p5-ch07）。
**怎么做**：① 起算日——申请日/优先权日或送达日（邮寄自发文日满 15 日推定）；② 届满日遇休假日顺延；③ 法定期限不可延长，指定期限可按月缴费延长；④ 已耽误：先看是否四类不可恢复期限，否则以不可抗拒事由（障碍消除起 2 个月且届满起 2 年内）或正当理由（收到处分通知起 2 个月 + 恢复费）请求恢复并同时补办手续。
**取舍**：恢复请求本身有期限。

### 【细则】费用期限链
**何时用**：任何缴费问题（reg-ch10 第110–117条）。
**怎么做**：缴费日按缴纳日/邮戳日/银行汇出日；申请费、公布印刷费、附加费自申请日起2个月（或受理通知起15日）否则视为撤回，优先权要求费同缴否则视为未要求；请求类费用逾期视为未提出；授权当年年费随登记手续缴；后续年费上一年度期满前缴，滞纳期6个月、每超1个月加5%，期满未缴自应缴日终止。
**取舍**：多缴、错缴3年内可退；缴费困难可减缴。

## 六、复审与无效

### 【细则】复审与无效请求书准备
**何时用**：不服驳回决定，或请求宣告专利权无效（reg-ch04 第65–71条）。
**怎么做**：复审——请求书 + 理由（+ 证据），格式不合限期补正，否则视为未提出；无效——理由与证据逐项对应、一式两份、理由限于法定清单，请求日起1个月内补齐理由和证据，逾期可不予考虑；避免同样理由和证据再请求（一事不再理）。
**取舍**：无效程序指定期限不得延长；请求人缺席口审视为撤回，撤回不一定终止已成熟的决定。

### 【指南】无效请求的"具体说明"
**何时用**：撰写或审查无效宣告请求书（gl-p4-ch03 第3.3节）。
**怎么做**：每项理由指明证据并结合全部证据比较方案；多组结合指明最主要结合方式；请求日起一个月内补充，公知常识性证据、形式完善、针对反证的补证可至辩论终结。
**取舍**：未具体说明的理由不予考虑；同样理由和证据一事不再理。

### 【指南】外观设计整体观察、综合判断
**何时用**：外观设计"明显区别"预判与无效程序法23（gl-p1-ch03、gl-p4-ch05）。
**怎么做**：一般消费者视角，定相同点与区别点，评估其对整体视觉效果的影响；法23.1 单独对比看六种实质相同情形；法23.2 与现有设计或其特征组合比，转用、拼合、替换视为有启示，唯一出口是独特视觉效果。
**取舍**：相同/实质相同不得结合两项以上对比设计；在先权利冲突由请求人举证。

### 【指南】实用新型创造性的领域与数量限缩
**何时用**：实用新型无效或评价报告中的创造性（gl-p4-ch06 第4节）。
**怎么做**：默认只在所属技术领域找启示，跨相近领域须指出现有技术中的明确记载；对比文件一般一或两项，第三篇起先论证"简单的叠加"。
**取舍**：降低的是启示门槛，不省略三步法；材料、方法特征照算。

## 七、专利权期限补偿

### 【法】请求专利权期限补偿
**何时用**：发明授权时距申请日已满4年且距实审请求已满3年；或新药专利获上市许可。
**怎么做**：由专利权人向国务院专利行政部门提出请求；审批延迟补偿扣除申请人自身造成的延迟；新药补偿不超过5年且上市后总有效期不超过14年。（第42条第2、3款）
**取舍**：必须主动请求；申请人拖延不补。

### 【细则】期限补偿计算
**何时用**：发明专利授权慢，或新药相关发明专利（reg-ch05 第77–84条）。
**怎么做**：授权延迟——起算日 = 申请日满4年与实审请求日满3年中较晚者，天数 = 起算日至授权公告日 − 合理延迟（复审、中止等）− 申请人引起的延迟（逾期答复、延迟审查等），公告起3个月内请求；新药——上市许可起3个月内请求，一药一专利、一专利一药，天数 = 申请日至上市许可日 − 5年，受5年 / 14年上限，保护范围限于该新药及经批准适应症。
**取舍**：双报换取的发明不补偿；细则未定天数首尾计算口径。

### 【指南】授权延迟期限补偿计算
**何时用**：准备请求法42.2 补偿（gl-p5-ch09 第2节）。
**怎么做**：条件——申请日起满四年且实审请求日起满三年后授权；授权公告起三个月内请求；补偿天数 = 起算日至授权公告日 − 合理延迟（复审、中止、保全、诉讼）− 申请人引起的延迟（逾期答复、延期、恢复，按天计）。
**取舍**：实审请求之日以足额缴费日为准且不早于公布日；新药补偿另有 5 年 / 14 年上限。

## 八、开放许可与强制许可

### 【法】开放许可（权利人侧 / 实施人侧）
**何时用**：权利人想低成本广泛授权并减免年费；实施人想快速合法取得许可。
**怎么做**：权利人书面声明 + 明确费率与支付方式（实用新型/外观设计附评价报告）→ 公告；实施人书面通知权利人并按公告标准付费 → 即得许可；权利人可另给普通许可，不得给独占/排他许可；撤回须书面并公告，不影响在先许可；纠纷协商 → 部门调解或起诉。（第50–52条）
**取舍**：权利人失去排他授权的灵活性，换年费减免和交易效率。

### 【法】申请强制许可
**何时用**：权利人不实施/未充分实施、垄断行为、紧急状态/公共利益、公共健康药品出口、从属专利受阻。
**怎么做**：确认事由与门槛（不实施型：授权满3年且申请满4年、无正当理由）；不实施型和从属型先以合理条件请求许可并保留证据；向国务院专利行政部门申请；获准后不独占、不转授、付合理使用费（协商不成由部门裁决）；不服决定或裁决3个月内起诉。（第53–63条）
**取舍**：只适用于发明和实用新型；半导体仅限公共利益和反垄断事由；主要供应国内市场。

### 【细则】开放许可与强制许可流程
**何时用**：专利权人想开放许可，或请求强制许可（reg-ch06 第85–91条）。
**怎么做**：开放许可——授权公告后声明专利号、权利人、费率与支付方式、许可期限，排除五种禁止情形（独占/排他许可期内、中止、欠年费、未经质权人同意的质押、其他障碍），达成后备案；强制许可——请求书说理附证 → 副本送权利人限期答辩 → 决定前预告双方，使用费协商不成3个月内裁决。
**取舍**：虚假声明或骗取年费减免 → 警告 + 10万元以下罚款（第88、100条）。

### 【指南】开放许可声明前检查
**何时用**：专利权人准备声明开放许可（gl-p5-ch11）。
**怎么做**：全体专利权人同意 → 排除九项禁止情形（独占/排他许可存续、质押、保全、中止、年费滞纳、无效程序中等）→ 实用新型/外观设计附结论正面的评价报告 → 七项事项 + 使用费简要说明（≤2000 字）→ 公告生效 → 合同生效后备案并申请年费减缴。
**取舍**：开放许可期间只能另给普通许可；撤回也须公告后生效。

## 九、保护与维权

### 【法】选择维权路径
**何时用**：发现侵权。
**怎么做**：先固定证据（必要时诉前证据保全）；需要快速停止 → 请求管理专利工作的部门处理（可责令立即停止；对方15日内不起诉又不停止可申请强制执行）；需要赔偿 → 向法院起诉（或先在行政程序中调解赔偿）；即将受难以弥补损害 → 诉前行为保全/财产保全；全国重大影响案件可请国务院专利行政部门处理，跨区域案件可请上级部门合并处理。（第65、70、72、73条）
**取舍**：行政快但不判赔偿；司法全面但周期长；两者可并行。

### 【法】主张与证明赔偿
**何时用**：起诉索赔。
**怎么做**：按阶梯举证——实际损失或侵权获利 → 许可费倍数 → 法定赔偿（3万–500万）；有故意且情节严重证据（警告函后继续、扩大规模等）→ 主张1–5倍惩罚性赔偿；账簿在对方手中 → 申请法院责令提供，对方不提供则请求参考己方主张判定；一并主张合理开支。新产品制造方法专利 → 要求对方证明其方法不同。实用新型/外观设计 → 备好专利权评价报告。（第66、71条）
**取舍**：法定赔偿最省举证但金额受限；惩罚性赔偿依赖对"故意 + 情节严重"的证明。

### 【法】侵权抗辩组合（被告侧）
**何时用**：被诉侵权。
**怎么做**：依次检查——技术方案是否落入权利要求（第64条）；是否现有技术/现有设计（第67条）；是否权利用尽、先用权、临时过境、科研实验、行政审批 Bolar 例外（第75条）；是否合法来源（第77条，仅免赔偿）；是否已过3年诉讼时效（第74条）；同时向国务院专利行政部门请求宣告无效（第45条）。
**取舍**：无效成功则自始不存在，但已执行判决不追溯（第47条）；合法来源不免除停止销售。

### 【法】药品上市阶段的专利争议
**何时用**：仿制药申请上市，或原研专利权人发现仿制申请。
**怎么做**：任一方可向法院起诉请求确认注册药品技术方案是否落入专利保护范围，或向国务院专利行政部门请求行政裁决；药监部门可依生效裁判决定是否暂停批准。（第76条）
**取舍**：提前解决争议避免上市后侵权，但具体衔接办法在本法之外。

## 十、国际申请（PCT 与海牙）

### 【细则】PCT 进入国家阶段清单
**何时用**：指定中国的国际申请（reg-ch11 第118–135条）。
**怎么做**：优先权日起30个月内办进入（32个月付宽限费）→ 中文声明 + 缴费 + 说明书权利要求书译文齐备才有进入日 → 进入日起2个月补修改译文、宽限期证明、优先权费、恢复优先权，4个月补保藏事项 → 译文错误改正限公布准备前或进入实审通知起3个月 → 未检索部分缴单一性恢复费 → 国际阶段被拒绝申请日或视为撤回的2个月内可请求复查。
**取舍**：32个月未进入 → 效力终止且不能依第6条恢复；授权后译文错误"大则缩至原文、小则维持"。

### 【指南】PCT 进入国家阶段核对
**何时用**：办理或审查国际申请进入中国（gl-p3-ch01、gl-p3-ch02）。
**怎么做**：优先权日起 30 个月内办进入手续 → 核对国际公布文本是否指定中国、有无撤回记录 → 进入声明逐项对扉页（申请日、类型、发明人/申请人、审查基础文本）→ 译文完整忠实、附图中文化 → 第19/34条修改译文进入日起 2 个月 → 实审以审查基础声明文本为准，法33 以原始国际申请文件为基准。
**取舍**：ISR/IPRP 只是参考；耽误 30 个月后不予恢复。

### 【细则】海牙外观设计国际申请接入
**何时用**：指定中国的外观设计国际注册申请（reg-ch12 第136–144条）。
**怎么做**：国际注册日 = 申请日；国际局公布后审查并通报结果；自公布起优先权副本3个月、宽限期证明2个月、分案2个月；无驳回理由则给予保护并公告生效；权利变更在国际局办妥后向中国局补证明。
**取舍**：本章未定的后果回落到专利法与细则其他各章（第136条第2款）。

### 【指南】海牙国际申请审查路径
**何时用**：指定中国的外观设计国际申请（gl-p6-ch01、gl-p6-ch02）。
**怎么做**：国际注册日即申请日；国际公布后给国家申请号；只审明显实质性缺陷与手续；结论向国际局发给予保护声明或驳回通知；分案、优先权证明、宽限期证明自国际公布起算。
**取舍**：审查文本是国际局英文文本，申请人可中文陈述、英文修改；视为未要求优先权后不予恢复。
