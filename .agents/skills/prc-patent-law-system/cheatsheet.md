# 速查表 — 专利法 · 实施细则 · 审查指南（三层并列）

每一行同时给出三层出处：**法** = 专利法条文号，**细则** = 实施细则条文号（2023 年编号），**指南** = 章节 ID（`gl-pN-chNN`，对应 `chapters/` 下文件）。"—" 表示该层没有对应规定，或章节文件未涉及。法条本身读 `law-` 章节，程序细节读 `reg-` 章节，审查标准读 `gl-` 章节。

## 决策规则

**申请路线与权利归属**
- 申请类型：有"方法"→ 发明；只有形状/构造且要快 → 实用新型；两者都想要 → 同日双申请，申请时分别声明，授权前放弃实用新型，不放弃 → 驳回（法2、9；细则47）。
- 客体：权利要求除主题名称外只有算法/规则 → 法25.1(2) 排除；含任一技术特征 → 法2.2 三要素（gl-p2-ch09）。医药用途"用于治疗…"→ 法25.1(3) 不授权；"制备治疗 Y 病药物的应用"→ 可授（gl-p2-ch10）。
- 归属：执行单位任务 或 主要用单位资源 → 单位；否则 → 个人；仅用资源且有约定 → 从约定（法6；细则12 含离职 1 年内）。
- 公开在申请前：属法24 四种情形且 ≤6 个月 → 仍可申请，但须申请时声明 + 2 个月证明（细则33）；否则 → 新颖性已失。
- 向外国申请：技术方案实质内容在中国完成 → 先保密审查，否则中国不授权；直接向专利局提 PCT 视为已请求（法19；细则8、9）。
- 转让：书面合同 + 登记公告 → 登记之日生效（法10）；共有无约定 → 只能单独实施或给普通许可，独占/排他/转让须全体同意（法14）。

**期限与费用**
- 递交日按邮戳日 / 进入系统日；专利局文件对你自发文日满 15 日推定送达（细则4）；汇款缴费日是邮戳日 / 银行汇出日，不是专利局收到日（细则111）。
- 耽误的是宽限期、优先权期限、专利权期限或诉讼时效 → 不可恢复；其余先看不可抗拒（2 个月 + 2 年内）再看正当理由（2 个月 + 费）（细则6；gl-p5-ch07）。
- 审查意见：任何"指定期限"→ 默认后果是视为撤回，不是延期（法35–37）；想延长须在届满前请求（细则6）。

**审查与答复**
- 新颖性：下位公开破坏上位，反之不然；数值范围落入、共同端点、重叠 → 无新颖性，完全落在对比范围内且无共同端点 → 有（gl-p2-ch03）。
- 创造性：区别特征为公知常识 / 同一文件他处 / 另一文件且作用相同 → 显而易见；预料不到的技术效果 → 具备创造性（法22.3；gl-p2-ch04）。
- 修改：不能从原记载直接地、毫无疑义地确定 → 超范围（法33）；答复中扩大独权、换主题、加权利要求 → 不接受（gl-p2-ch08）；主动修改只在细则57 窗口内。
- 分案：原申请尚在审且未过登记期限 → 可；驳回 / 撤回 / 视为撤回后 → 不能（细则48）。
- 驳回：实审驳回只能引细则59 清单且须已听证；初审明显缺陷按三份清单（细则50）；救济固定两级 3 个月复审 → 3 个月起诉，不能跳级（法41）。

**复审与无效**
- 无效程序中专利权人 → 只能缩小（删权利要求、删方案、进一步限定、改明显错误）；请求人 → 1 个月内补齐理由证据，指定期限不延长（细则71、73、75；gl-p4-ch03）。
- 口审：请求人不回执且不出席 → 视为撤回；专利权人不出席 → 缺席审理（细则74；gl-p4-ch04）。
- 实用新型创造性引三篇以上或跨领域 → 须论证"简单的叠加"或明确启示（gl-p4-ch06）；外观设计转用、拼合、替换 → 无明显区别，除非独特视觉效果（gl-p4-ch05）。

**补偿与许可**
- 授权延迟补偿 → 申请日满 4 年且实审请求日满 3 年后授权才有；双报换取的发明 → 不补（法42；细则78）。
- 开放许可 → 授权公告后声明；排除独占/排他许可期内、中止、欠年费、未经质权人同意的质押等情形；实用新型/外观设计附评价报告（法50、51；细则85、86；gl-p5-ch11）。

**维权与防御**
- 维权：要快停 → 行政处理；要赔偿 → 法院；怕证据灭失/损害不可弥补 → 诉前保全（法65、72、73）；对方的无效请求被受理 → 可请求中止处理（细则98）。
- 赔偿举证：损失/获利 → 许可费倍数 → 法定赔偿；对方藏账簿 → 请求责令提供并按己方主张判（法71）。
- 被告防御顺序：不落入权利要求 → 现有技术 → 法75 五种例外 → 合法来源（只免赔）→ 时效 → 同时提无效（法64、67、75、77、74、45）。

## 决策树

**侵权判断（法）**
1. 行为是否在法11 动词清单内且为生产经营目的？否 → 不侵权。
2. 技术方案/外观是否落入权利要求（或图片照片）范围？（法64）否 → 不侵权。
3. 是否属于现有技术/现有设计？（法67）是 → 不侵权。
4. 是否属于法75 五种情形（权利用尽、先用权、临时过境、科研实验、行政审批）？是 → 不视为侵权。
5. 是否合法来源的不知情销售/使用者？（法77）是 → 停止但不赔偿。
6. 是否超过 3 年时效？（法74）是 → 抗辩时效。
7. 否则 → 侵权成立，进入法71 赔偿阶梯。

**客体（指南 gl-p2-ch01）**：① 法5（违法、违德、害公、违规遗传资源）→ 不授权 ② 法25 六类（智力活动规则看"仅仅涉及"，诊断方法看"活体 + 直接结论"，治疗方法看目的）→ 排除 ③ 法2.2 三要素不齐 → 非技术方案 ④ 通过 → 审三性。

**修改能否接受（指南 gl-p2-ch08 / gl-p4）**：① 超出原记载（法33）→ 否 ② 实审须针对通知书缺陷 / 复审仅限消除驳回缺陷（细则66）/ 无效只做减法（细则73）→ 不符则否 ③ 克服缺陷且无新缺陷 → 接受。

## 失权信号（看到就要警惕）

- 申请日将满 3 年未请求实审；一通 4 个月 / 再通 2 个月或任何"指定期限"临近无人处理。
- 申请费 2 个月（或受理通知 15 日）、授权登记 2 个月将届满未办。
- 优先权声明有了但副本未交（16 个月 / 3 个月）；保藏证明（4 个月）、宽限期证明（2 个月）只声明未补件。
- 年费进入 6 个月滞纳期。
- 产品发布 / 论文发表排在申请之前。
- 在中国研发完成、未经保密审查就准备向外国申请。
- 实用新型 / 外观设计准备维权或声明开放许可但没有专利权评价报告。
- 无效请求提出后 1 个月补证期将过；收到复审 / 无效决定近 3 个月未起诉；归属纠纷中止满 1 年未请求延长。
- PCT 优先权日起 30 / 32 个月将届满未办进入手续。
- 知道侵权已近 3 年仍未起诉。
