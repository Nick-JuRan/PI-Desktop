# 审查指南 · 第二部分 第十章 关于化学领域发明专利申请审查的若干规定

> 来源层：《专利审查指南》（2023年版）｜本章 ID：`gl-p2-ch10`｜同一主题在另两层的章节见文末「关联」；条文级对照见 [crosswalk.md](../crosswalk.md)

## 核心要点
化学发明能否实施难以预测、结构不清须借参数或制法定义、已知产品的新用途不是新产品、生物材料靠文字难以再现（第1节），因此公开押在实验数据和实施例上，权利要求按化合物/组合物/参数或制法表征产品/方法/用途分类撰写，新颖性用「结构推定」和「用途实质」判断，创造性看结构改造带来的用途或效果是否预料不到；生物技术发明再叠加客体排除、保藏、序列表和遗传资源披露。

## 引入的框架

### 一、不授予专利权的化学发明（第2节、第9.1节）
- 天然物质（第2.1节，法25.1(1)）：天然形态的物质是科学发现；首次分离提取、结构或理化参数为现有技术不曾认识、能确切表征、有产业利用价值的，物质及取得方法均可授权；基因/DNA片段（第9.1.2.2节）、纯培养且有特定工业用途的微生物（第9.1.2.1节）同理。
- 医药用途（第2.2节，法25.1(3)）：诊断治疗用途不授权，制造药品用途可授权。
- 生物技术客体（第9.1节）：法5.1排除各形成发育阶段的人体（生殖细胞、受精卵、胚胎、个体；人类胚胎干细胞除外），法5.2排除依赖违法获取或利用的遗传资源完成的发明；法25.1(4)：动物胚胎干细胞、动物个体及生殖细胞、受精卵、胚胎属「动物品种」，体细胞、组织、器官不属；能光合作用维系生存的植株及繁殖材料属「植物品种」，不具此特性的细胞、组织、器官不属；转基因动植物仍属动植物品种；微生物不属动植物（第9.1.2节）。

### 二、化学发明的充分公开（第3节、第9.2节，法26.3）
- 化学产品三要素（第3.1节）：确认——化合物写名称及结构式或分子式＋与技术问题相关的理化参数，高分子加分子量分布和重复单元排列，组合物写组分、状态、可选范围、含量及其影响，结构不明产品用参数或制法；制备——至少一种制法，化合物通常需制备实施例；用途/效果——结构首创化合物也须至少一种用途，据现有技术不能预测时须记载定性或定量实验数据，新药物须记载具体医药用途或药理作用、有效量及使用方法，不能预测时须有实验室（含动物）或临床数据。方法发明写原料、步骤、条件（第3.2节）；用途发明写产品、使用方法、效果（第3.3节）；实施例数目须足以判断整个权利要求范围都能实施并取得效果（第3.4节）。
- 补交实验数据（第3.5节）：充分公开以原说明书和权利要求书为准；申请日后为满足法22.3、法26.3补交的数据应当予以审查，标准是所证明的技术效果能够从专利申请公开的内容中得到（第3.5.1节）。
- 生物材料保藏（第9.2.1节，细则27）：文字无法使人获得材料时须向认可的保藏单位（布达佩斯条约国际保藏单位，如CGMCC、CCTCC、GDMCC）保藏；公众不能得到的材料未保藏，或未在申请日或最迟自申请日起四个月内交保藏证明和存活证明的，以法26.3驳回；请求书和说明书均写分类命名、拉丁文学名、保藏单位、日期、编号。「公众不能得到」含非专利程序保藏不公开发放的和制法不可重复的（不可再现的筛选、突变菌种）；商业渠道可购、已在承认的保藏机构保藏且申请日前公布或授权、已在非专利文献公开并保证二十年内发放的无需保藏。
- 遗传工程产品（第9.2.2节）：写序列，不能则写理化参数、生物学特性或制法；按基因/载体、转化体、多肽、融合细胞、单抗分别写制备步骤，并以证据证明功能；制法不可重复的转化体、融合细胞及以特定结合常数限定的单抗的杂交瘤须保藏（能证明可重复制备的除外）。序列表（第9.2.3节，细则20.4）：≥10核苷酸或≥4个L-氨基酸须交电子序列表，与书面不一致以书面为准。微生物写株种属名并括注拉丁文学名及保藏信息，新种详记分类学性质（第9.2.4节）。

### 三、化学发明的权利要求（第4节、第9.3节，法26.4、细则23.2）
- 化合物用名称、结构式或分子式表征，不许商品名或代号（第4.1节）。
- 组合物开放式/封闭式（第4.2.1节）：开放式（「含有」「包括」「主要由……组成」等）不排除未指出的组分；封闭式（「由……组成」「余量为」）仅含所列组分，允许通常含量的杂质。开放式须有说明书对其他组分的支持。A+B+C+D对开放式A+B+C是从属权利要求，对封闭式是独立权利要求。
- 组分与含量（第4.2.2节，细则23.2）：发明实质涉及含量的必须同时限定组分和含量，否则缺少必要技术特征；合金通常应限定必要成分及含量；不得用「大约」；「0～X」为选择组分，「＜X」含X＝0，通常不许「＞X」；百分数之和＝100%，且某组分上限＋其他组分下限≤100、下限＋其他上限≥100。
- 组合物三型（第4.2.3节）：非限定型、性能限定型、用途限定型；说明书仅公开一种性能或用途的通常写后两型，大多数药品权利要求应写成用途限定型。
- 结构不明产品允许用清楚的理化参数和/或制备方法表征（第4.3节）；化学方法用工艺、物质、设备三类特征限定（第4.4节）。
- 用途权利要求（第4.5节）：用途发明的本质是产品性能的应用，属方法类型；「X作为杀虫剂的应用」是用途权利要求，「含X的杀虫剂」是产品权利要求，二者不等同（第4.5.1节）。医药用途「用于治病」「作为药物的应用」落入法25.1(3)，须写成药品权利要求或「化合物X作为制备治疗Y病药物的应用」等制药方法类型（第4.5.2节）。
- 生物技术权利要求（第9.3节）：基因/蛋白质限定序列或参见SEQ ID NO；「取代、缺失或添加一个或几个氨基酸且具有酶A活性」式限定须说明书例举衍生物并记载制备和验证手段；「严格条件下杂交」式限定须详述严格条件并例举DNA；兜底才可用功能、来源、方法（第9.3.1.1、9.3.1.5节）。重组载体＝基因＋载体，转化体＝宿主＋导入基因，单抗用CDR序列或杂交瘤保藏号（第9.3.1.3～9.3.1.7节）。微生物写中文名括注拉丁文学名加保藏编号；无实施方式的突变株不得保护，「衍生物」范围不清楚（第9.3.2节）。

### 四、新颖性（第5节、第9.4.1节，法22.2）
- 化合物（第5.1节）：对比文件结构信息足以认定已公开的无新颖性，申请人证明申请日前无法获得的除外；结构信息不足但结合理化参数、制法、效果数据推定实质相同的无新颖性，除非申请人证明结构确有差异。通式不破坏具体化合物；具体化合物破坏包含它的通式但不影响其他化合物；范围C1-4破坏两端C1、C4，不破坏C4的各异构体；天然物质仅在结构形态一致或直接等同时破坏。
- 组合物（第5.2节）：对比文件A+B+C——封闭式「由A+B组成」新，开放式「含有A+B」且技术问题相同不新，排除法「不含C」新；含量适用第三章第3.2.4节。
- 参数/制法表征产品（第5.3节）：无法据参数比较即推定不新；制法表征审产品本身，未给可比较参数、也未表明制法差异改变性能的推定不新。
- 用途发明（第5.4节）：新产品的用途自然新；已知产品不因新用途成为新产品（「用作增塑剂的产品X」不新），但新用途本身作为使用方法评价新颖性。医药用途四考量：新用途是否实质不同、是否被已知机理或药理作用直接揭示、是否为已知用途的上位概念、给药对象方式途径用量间隔等是否对制药过程有限定作用——仅体现在用药过程的区别不带来新颖性。
- 遗传工程（第9.4.1节）：蛋白质新则编码基因新；已知蛋白质的同序列重组蛋白不因制法而新；抗原新则单抗新，但与已知抗原表位相同的推定单抗不新，除非申请人证明确实不同。

### 五、创造性（第6节、第9.4.2节，法22.3）
- 化合物三步（第6.1节）：结构差异→基于该结构改造获得的用途/效果确定实际解决的技术问题→现有技术整体是否给出通过该改造解决该问题的启示；仅经合乎逻辑的分析、推理或有限试验即可完成的视为有启示；用途改变或效果改进预料不到即非显而易见；效果沿已知必然趋势（杀虫效果随烷基碳数增加而提高）的无创造性。
- 用途发明（第6.2节）：新产品用途不能从结构组成相似的已知产品预见→有；已知产品用途不能从结构、组成、分子量、理化性质及现有用途预见，且利用新发现性质产生预料不到效果→有。组合物、制备方法、选择发明回到第四章一般规则。
- 生物技术（第9.4.2节）：基因——编码蛋白序列不同且性能不同或改善、无启示→有；蛋白序列已知或易确定→编码基因无，除非特定序列有预料不到效果；同物种自然突变体、功能相同→无。重组载体、转化体、融合细胞——已知元件简单结合通常无，特定结合有预料不到效果→有。单抗——抗原已知，关键序列明显不同、无启示、有益效果→有；免疫原性清楚的抗原仅用抗原限定→无，加杂交瘤限定且效果预料不到→有。微生物——新种→有；已知种同属替换→无，除非效果预料不到。

### 六、实用性（第7节、第9.4.3节，法22.4）
不能重复的菜肴和烹调方法、医生处方及据处方配药无实用性（第7.1、7.2节）；自然界筛选特定微生物、物理化学诱变生产新微生物的方法因随机性不能重现，一般无实用性，申请人充足证据证明可重复的除外（第9.4.3节）。

### 七、单一性（第8节，法31.1、细则39）
- 马库什权利要求（第8.1节）：一项权利要求限定多个并列可选择要素；要素为化合物时须(1)共同的性能或作用，且(2)构成与现有技术区别特征并对该作用必不可少的共同结构，或不能有共同结构时属于本领域公认的同一化合物类别（可预期成员表现相同、可互替）（第8.1.1节）。示例（第8.1.2节）：共有吲哚母核已被现有技术用于同一作用→母核不构成区别特征→无，R1改为3-吡啶基使3-吡啶基吲哚成为必不可少的区别性共同结构→有；酯化物一种抗热降解一种不抗→无；分属不同类杂环或跨无机盐/有机盐/酰胺/腈/苯酚/胺/杂环七类→无；催化剂「X或X+A」作用相同且共有必不可少的X→有。
- 中间体与最终产物（第8.2节）：基本结构单元相同或密切相关且进入最终产物，并且最终产物直接由中间体制备或分离→有单一性；用于最终产物不同结构部分的不同中间体不能合案。

### 八、遗传资源来源披露（第9.5节，法26.5、细则29.2）
直接来源＝获取遗传资源的直接渠道（时间、地点、方式、提供者）；原始来源＝所属生物体在原生环境中的采集地（时间、地点、采集者）（第9.5.1节）。依赖遗传资源的发明须在请求书中说明并填写登记表，直接来源机构能提供原始来源的应提供，无法说明须陈述理由（第9.5.2节）。审查先确定是否及依赖何种遗传资源；未交登记表→通知补交并指明；部分披露→补全；仍不符合法26.5→驳回；登记表不属于原始记载，不能作为充分公开的依据或修改基础（第9.5.3节）。

## 关键概念
- 天然物质 — 天然形态存在的物质是科学发现，首次分离提取、能确切表征且有产业利用价值的可授权（第2.1节）。
- 制药用途权利要求 — 「化合物X作为制备治疗Y病药物的应用」式的制药方法类用途权利要求，用以避开法25.1(3)（第4.5.2节）。
- 开放式/封闭式 — 「含有」不排除其他组分，「由……组成」仅含所列组分并允许通常含量的杂质（第4.2.1节）。
- 参数或制法表征的产品 — 结构不明产品的表征方式，无法与现有产品比较即推定无新颖性（第4.3、5.3节）。
- 用途发明 — 基于发现产品新性能并利用之的发明，本质是使用方法发明（第4.5.1、5.4节）。
- 化合物新颖性的推定 — 结构信息不足时综合参数、制法、效果推定实质相同，举证责任转至申请人（第5.1节）。
- 必然趋势 — 现有技术已指出的效果变化规律，沿其得到的改进不构成创造性（第6.1节(3)）。
- 电子等排体置换 — NH2/CH3、-O-/-NH-等经典等排体替换通常有动机，仅在效果预料不到时有创造性（第6.1节例3、例4）。
- 补交实验数据 — 申请日后补交的数据应予审查，所证明效果须能从原申请公开内容中得到（第3.5节）。
- 公众不能得到的生物材料 — 非专利程序保藏且不公开发放的，或制法不可重复获得的，须按细则27保藏（第9.2.1节）。
- 马库什要素 — 马库什权利要求中性质相类似、技术上相互关联的并列可选择要素（第8.1.1节）。
- 直接来源/原始来源 — 遗传资源的获取渠道与所属生物体在原生环境中的采集地（第9.5.1节）。

## 思维模型
- 拿到化学产品权利要求先问「用什么表征」：结构清楚→名称/结构式（第4.1节）；组合物→组分±含量、开放或封闭、是否须用途限定（第4.2节）；结构不明→参数或制法（第4.3节），并立刻想到第5.3节「无法比较即推定不新」，说明书必须给出可比较的参数。
- 看到「用途」就问「方法还是产品、治疗还是制药」：用途发明本质是使用方法（第4.5.1节），医药用途改写为制药用途（第4.5.2节），新颖性看使用方法本身且给药特征不算（第5.4节），创造性看能否从结构、已知性质、现有用途预见（第6.2节）。
- 评化合物创造性用「结构差异→效果→启示」：同母核、等排替换默认有动机，须以预料不到的效果或用途改变反转；沿必然趋势的效果不算；通式与具体化合物分开评（第6.1节）。
- 涉及能自我复制的材料先问「文字能否重现」：不能→保藏并四个月内交证明（第9.2.1节）；≥10核苷酸/≥4氨基酸→序列表（第9.2.3节）；靠随机筛选或诱变→实用性风险（第9.4.3节）；取自生物体→登记表，且登记表不能补公开（第9.5节）。

## 反模式
- 说明书只写「具有某活性」而无效果记载和测定方法，事后补交数据 → 所证明效果不能从原申请公开内容中得到，挽救不了公开不充分（第3.5.1节）。
- 医药用途写成「X用于治疗Y病」 → 落入法25.1(3)（第4.5.2节）；以给药剂量、对象、间隔区别制药用途 → 不带来新颖性（第5.4节）。
- 开放式「含有A+B」而说明书只描述A+B+C → 得不到支持（第4.2.1节），且对比文件A+B+C破坏其新颖性（第5.2节）。
- 含量用「大约」「＞X」或百分数之和凑不成100% → 不清楚（第4.2.2节）；以制法定义产品却不给可比较参数 → 推定不新（第5.3节）。
- 凭「结构相近类似物活性相当」为整个通式主张创造性 → 结构接近正是有动机替换的理由，只能就有预料不到效果的具体化合物主张（第6.1节例5）。
- 马库什通式覆盖不同类杂环或多类结构各异的化合物、仅共有用途 → 无共同结构也非公认同一类别，无单一性（第8.1.2节例3、例4）。
- 保护微生物「衍生物」或无实施方式的突变株 → 不清楚/不允许（第9.3.2节）；「取代、缺失或添加」概括却未例举衍生物、未记载制备验证手段 → 公开不充分（第9.3.1.1节）。
- 已保藏但四个月内未交保藏证明和存活证明，或以不可再现的筛选/突变制法代替保藏 → 法26.3驳回（第9.2.1节）；拿登记表信息补说明书 → 不属于原始记载（第9.5.3节）。

## 实例演练
1. 补交实验数据（第3.5.2节）。例1：权利要求保护化合物A，说明书记载制备实施例、降血压作用和测定方法但无结果数据，申请人补交降血压效果数据。结论：应予接受——A的降血压作用已在原始记载中公开，补交数据所证明的效果能从申请公开内容中得到；该数据在审查创造性时也应予以审查。例2：权利要求保护通式I，说明书有化合物A、B的制备实施例、抗肿瘤作用及测定方法，记载IC50在10～100 nM；申请人补交A为15 nM、对比文件1化合物为87 nM的对比数据。结论：应予审查——A及其抗肿瘤作用已公开；但审查员还须结合该数据进一步分析是否具备创造性，数据可采不等于创造性成立。
2. 化合物创造性（第6.1节例2～例5）。例3：氨基-磺酰脲与甲基-磺酰脲仅差NH2与CH3，均为抗糖尿病药且效果相当→无创造性：经典一价电子等排体，为获得相当活性有动机置换。例4：嘌呤6位以-O-替换-NH-→有创造性：虽同为公知等排体，但癌细胞生长抑制活性提高约40倍，属预料不到的技术效果。例5：通式Vb仅以-S-替代Va的-O-连接原子，性质接近、有动机替换→通式无创造性；具体化合物Vb1连接原子和R3取代基均不同且抗乙肝病毒活性明显优于Va、无启示→有创造性。例2：磺胺插入-CONH-成磺酰脲，抗菌素变抗糖尿病药，用途完全不同、无动机→有创造性。
3. 已知产品的新用途（第5.4节）。产品X作洗涤剂已知：「用作增塑剂的产品X」是产品权利要求→不新；后来发现X配以某添加剂可作增塑剂，如何配制、选何添加剂、配比多少构成使用方法特征→就该使用方法本身评价新颖性，不能凭X已知否定。

## 关键要点
1. 化学产品说明书「三件齐」：确认、至少一种制法（化合物要制备实施例）、至少一种用途或效果；用途不可预测须原始记载实验数据，药物还须有效量和使用方法（第3.1节）。
2. 补交实验数据只能「坐实原已公开的效果」：接受与否看效果能否从原申请公开内容中得到，采纳后仍须独立评创造性（第3.5节）。
3. 医药用途统一写成「X在制备治疗Y病药物中的应用」；新颖性靶向实质不同的用途，不靠给药方案（第4.5.2、5.4节）。
4. 组合物先定开放或封闭：开放式须说明书支持且面对A+B+C对比文件失新颖性，封闭式或「不含C」可保新颖性（第4.2、5.2节）；参数或制法表征的产品必须给出可比较的参数或制法带来的性能变化，否则推定不新（第4.3、5.3节）。
5. 化合物创造性按「结构差异—效果—启示」三步：结构接近或等排替换须以预料不到的效果反转，沿必然趋势的改进不算，通式与具体化合物分别评（第6.1节）。
6. 马库什单一性双条件：共同性能或作用＋构成区别特征且必不可少的共同结构（或公认同一化合物类别）（第8.1节）。
7. 生物技术四张清单：文字不能重现即保藏并在申请日起四个月内交证明（第9.2.1节）；≥10核苷酸/≥4氨基酸交序列表（第9.2.3节）；随机筛选或诱变方法防实用性缺陷（第9.4.3节）；依赖遗传资源填登记表（第9.5节）。
