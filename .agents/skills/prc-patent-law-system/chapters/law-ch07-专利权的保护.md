# 专利法 · 第七章 专利权的保护（第64–80条）

> 来源层：《中华人民共和国专利法》（2020年修正）｜本章 ID：`law-ch07`｜同一主题在另两层的章节见文末「关联」；条文级对照见 [crosswalk.md](../crosswalk.md)

## 核心要点
维权分五步：定范围（第64条）→ 选路径（行政或司法，第65、70条）→ 举证（第66、71–73条）→ 算赔偿（第71条，含惩罚性与法定赔偿）→ 应对抗辩（第67、75、77条）。2020年新增惩罚性赔偿、法定赔偿上调至500万、举证妨碍规则和药品专利链接。

## 引入的框架
- **保护范围（第64条）**：发明/实用新型以权利要求的内容为准，说明书及附图可用于解释权利要求；外观设计以图片或照片中的产品外观设计为准，简要说明可用于解释。
- **双轨维权（第65、70条）**：未经许可实施即侵权 → 协商；不愿或不成 → 向人民法院起诉，或请求管理专利工作的部门处理。行政处理认定侵权可责令立即停止；不服 → 收到处理通知15日内依行政诉讼法起诉；期满不起诉又不停止 → 部门申请法院强制执行。行政部门可应请求调解赔偿数额，不成 → 民事诉讼。国务院专利行政部门可处理全国有重大影响的纠纷；地方部门可合并处理本区域内侵犯同一专利权的案件，跨区域可请求上级部门处理。
- **举证规则（第66条）**：涉及新产品制造方法的发明专利 → 制造同样产品者应证明其制造方法不同（举证责任倒置）；涉及实用新型或外观设计 → 法院或部门可要求专利权人或利害关系人出具专利权评价报告作为证据，各方也可主动出具。
- **赔偿计算的四层阶梯（第71条）**：① 权利人实际损失 或 侵权人获利 → ② 难以确定时参照专利许可使用费的倍数合理确定 → ③ 故意侵权且情节严重的，在①②确定数额的1倍以上5倍以下确定（惩罚性赔偿）→ ④ ①②均难以确定时，法院根据专利类型、侵权性质和情节等酌定3万元以上500万元以下（法定赔偿）。赔偿数额还应包括权利人为制止侵权支付的合理开支。举证妨碍：权利人已尽力举证、账簿资料主要由侵权人掌握 → 法院可责令提供；不提供或提供虚假的 → 可参考权利人主张和证据判定。
- **诉前保全（第72、73条）**：有证据证明他人正在或即将实施侵权、不及时制止将受难以弥补的损害 → 起诉前可申请财产保全、责令作出或禁止作出一定行为（行为保全）；证据可能灭失或以后难以取得 → 起诉前可申请证据保全。
- **诉讼时效（第74条）**：侵权诉讼时效3年，自权利人知道或应当知道侵权行为**以及**侵权人之日起算；临时保护期使用费的时效3年，自知道或应当知道他人使用之日起算，但授权前已知道的自授权之日起算。
- **不视为侵权的五种情形（第75条）**：(一) 权利用尽：专利产品或依专利方法直接获得的产品由专利权人或经其许可售出后的使用、许诺销售、销售、进口；(二) 先用权：申请日前已制造相同产品、使用相同方法或已作好必要准备，且仅在原有范围内继续；(三) 临时过境的外国运输工具为自身需要使用；(四) 专为科学研究和实验使用；(五) 为提供行政审批所需信息制造、使用、进口专利药品或专利医疗器械，以及专门为其制造、进口（通称 Bolar 例外）。
- **现有技术/现有设计抗辩（第67条）**：被控侵权人证明其实施的技术或设计属于现有技术或现有设计 → 不构成侵权。
- **合法来源抗辩（第77条）**：为生产经营目的使用、许诺销售或销售不知道是未经许可制造并售出的侵权产品，能证明合法来源 → 不承担**赔偿**责任（不免除停止侵权）。
- **药品专利链接（第76条，2020年新增）**：药品上市审评审批中，上市许可申请人与专利权人/利害关系人就注册药品相关专利发生纠纷 → 可向人民法院起诉，请求就技术方案是否落入药品专利保护范围作出判决；药监部门在规定期限内可根据生效裁判决定是否暂停批准上市；也可请求国务院专利行政部门行政裁决；具体衔接办法由药监与专利行政部门制定报国务院同意。
- **假冒专利（第68、69条）**：民事责任 + 责令改正并公告 + 没收违法所得 + 违法所得5倍以下罚款；无违法所得或违法所得≤5万元 → 25万元以下罚款；构成犯罪追究刑责。执法措施：询问当事人、现场检查、查阅复制合同/发票/账簿、检查产品、查封扣押有证据证明是假冒专利的产品；处理侵权纠纷时可采取其中询问、现场检查、检查产品三项；当事人应协助配合。
- **公务约束（第78–80条）**：违反第19条向外国申请并泄露国家秘密 → 行政处分/刑责；管理专利工作的部门不得参与推荐专利产品等经营活动，违者责令改正、没收违法收入、处分责任人；工作人员玩忽职守、滥用职权、徇私舞弊 → 刑责或处分。

## 关键概念
- **利害关系人**：与专利权人并列的维权主体（如被许可人）。
- **合理开支**：律师费、调查费等，计入赔偿。
- **专利权评价报告**：实用新型/外观设计维权时的稳定性证明。
- **原有范围**：先用权的边界，不得扩大产能或用途。

## 思维模型
- 侵权分析两问：行为是否落入第11条的动词清单且为生产经营目的？技术方案是否落入第64条权利要求范围？两问皆是再看第67、75、77条抗辩。
- 赔偿从"实证"到"推定"逐级下沉：能证明损失或获利最好，其次参照许可费倍数，最后才是法定赔偿；恶意情节严重时在前两级基础上放大1–5倍。
- 行政路径快（可责令停止）、司法路径全（可判赔偿），常见做法是行政止损 + 司法索赔。

## 反模式
- **用说明书里的方案主张保护**：保护范围以权利要求为准，说明书只用于解释。
- **实用新型维权不备专利权评价报告**：程序可能被要求补交，且稳定性受质疑。
- **知道侵权3年后才起诉**：诉讼时效已过；且起算要求同时知道行为和侵权人。
- **对购买的侵权产品经销商只索赔不要求停止**：合法来源抗辩免的是赔偿，不免停止。
- **把先用权用于扩产**：只能在原有范围内继续。

## 实例演练
甲发现乙制造销售落入其发明专利权利要求1的产品。甲先向乙所在地管理专利工作的部门请求处理，部门认定侵权并责令立即停止（第65条）；乙15日内未起诉也未停止 → 部门申请法院强制执行。赔偿方面甲向法院起诉：甲无法证明自身损失，乙账簿在乙手中且乙拒不提供 → 法院依第71条第4款参考甲主张（例如按甲此前对丙的许可费50万元/年 × 2倍 = 100万元）判定；法院进一步认定乙曾收到警告函仍扩大生产，属故意且情节严重 → 在100万元基础上按2倍确定200万元，另加甲的律师费等合理开支。乙以"该技术在申请日前已公开"抗辩 → 若举证成立则依第67条不侵权；乙若只是从丁处进货的销售商且能证明合法来源 → 依第77条免赔偿但仍须停止销售。

## 关键要点
1. 保护范围看权利要求，不看说明书（第64条）。
2. 行政处理可责令停止（15日内起诉期），法院管赔偿；两条路可并行（第65条）。
3. 赔偿阶梯：损失/获利 → 许可费倍数 → 法定3万–500万；故意且严重可1–5倍（第71条）。
4. 诉前行为保全、证据保全是快速止损的工具（第72、73条）。
5. 三年时效、五种不视为侵权、现有技术抗辩、合法来源抗辩是被告的四张牌（第74、75、67、77条）。
6. 药品上市阶段可提前解决专利纠纷（第76条）。

## 关联
- **第一章**：第11条排他行为清单是侵权认定的动词表；第20条诚信原则约束恶意维权。
- **第五章**：被告的标准反击是无效宣告（第45条），第47条决定无效后已执行判决的命运。
- **第三章**：权利要求撰写质量（第26条）决定第64条的保护范围大小。
