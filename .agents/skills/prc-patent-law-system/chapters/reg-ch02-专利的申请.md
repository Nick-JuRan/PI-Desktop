# 实施细则 · 第二章 专利的申请（第17–41条）

> 来源层：《中华人民共和国专利法实施细则》（2023年修订）｜本章 ID：`reg-ch02`｜同一主题在另两层的章节见文末「关联」；条文级对照见 [crosswalk.md](../crosswalk.md)

## 核心要点
本章把专利法第26–32条的申请文件要求落成格式规范与手续时限：请求书九项、说明书五段、独立/从属权利要求写法、摘要与附图、外观设计图片与简要说明；再叠加生物材料保藏、遗传资源说明、不丧失新颖性声明三类特殊手续，以及优先权的副本、补正、恢复、增改和单一性标准。每项手续都带逾期后果：视为未提交保藏、视为未要求优先权、不适用法第24条、在先申请视为撤回。

## 引入的框架

### 1. 提交、代理与代表人（细则第17、18条；法第18条、第26条第1款）
- 申请文件须符合规定要求；委托代理机构的同时交写明委托权限的委托书（细则第17条第1、2款）。
- 申请人2人以上且未委托代理：除请求书另有声明外，第一申请人为代表人（细则第17条第3款）。
- 依法第18条第1款须委托代理的申请人/专利权人，仍可自行提交在先申请文件副本、缴费、办理规定的其他事务（细则第18条）。

### 2. 请求书九项（细则第19条；法第26条第2款）
- 名称；申请人身份信息（中国主体含地址、邮编、统一社会信用代码或身份证件号码，外国主体含国籍或注册地）；发明人/设计人姓名；代理机构与代理师信息；优先权三要素（在先申请日、申请号、原受理机构名称）；签字或盖章；申请文件清单；附加文件清单；其他事项（细则第19条）。

### 3. 说明书与附图（细则第20、21条；法第26条第3款）
- 名称与请求书一致；按技术领域、背景技术（尽可能引证文件）、发明内容（技术问题、技术方案、对照现有技术的有益效果）、附图说明、具体实施方式（优选方式，必要时举例并对照附图）五段撰写并逐段加标题，仅当变通既省篇幅又不妨碍理解时才允许（细则第20条第1、2款）。
- 用词规范、语句清楚；禁用"如权利要求……所述的……"式引用语和商业性宣传用语（细则第20条第3款）。
- 发明申请含核苷酸或氨基酸序列的须附符合规定的序列表；实用新型说明书必须有表示产品形状、构造或其结合的附图（细则第20条第4、5款）。
- 附图按"图1，图2，……"编号；附图标记与说明书文字双向对应，同一组成部分标记一致；附图中除必需词语外不加注释（细则第21条）。

### 4. 权利要求书（细则第22–25条；法第26条第4款）
- 记载技术特征；多项时用阿拉伯数字顺序编号；术语与说明书一致；可含化学式或数学式，不得含插图；除绝对必要外不得用"如说明书……部分所述"或"如图……所示"；特征后可括号引用附图标记，标记不构成限制（细则第22条）。
- 必须有独立权利要求，可有从属权利要求；独立权利要求从整体反映技术方案并记载必要技术特征，由前序部分（主题名称 + 与最接近现有技术共有的必要技术特征）和特征部分（"其特征是……"引出区别特征）组成，性质不适合的可用其他方式；一项发明或实用新型只有一个独立权利要求，写在其从属权利要求之前（细则第23、24条）。
- 从属权利要求 = 引用部分（被引编号 + 主题名称）+ 限定部分（附加技术特征）；只能引用在前的权利要求；多项从属只能择一引用，且不得作为另一项多项从属的基础（细则第25条）。

### 5. 说明书摘要（细则第26条；法第26条第3款）
- 写名称、技术领域、技术问题、技术方案要点、主要用途；可含最能说明发明的化学式；禁用商业性宣传用语；有附图的须在请求书中指定一幅最能说明技术特征的附图为摘要附图（细则第26条）。

### 6. 生物材料保藏与遗传资源（细则第27–29条；法第26条第3、5款）
- 触发条件：新的生物材料 + 公众不能得到 + 说明不足以使所属领域技术人员实施（细则第27条）。
- 手续：①最迟在申请日（有优先权的指优先权日）将样品交认可的保藏单位，并在申请时或最迟自申请日起4个月内交保藏证明和存活证明，逾期→样品视为未提交保藏；②申请文件中提供该材料的特征资料；③请求书和说明书写明分类命名（注拉丁文名称）、保藏单位名称、地址、保藏日期、保藏编号，未写的自申请日起4个月内补正，逾期→视为未提交保藏（细则第27条第（一）–（三）项）。
- 发明申请公布后，任何人要以实验目的使用该材料，须向国务院专利行政部门提出请求，写明名称与地址，并保证不向他人提供、授权前仅作实验目的使用（细则第28条）。
- 遗传资源 = 取自人体、动物、植物或微生物等、含遗传功能单位且有实际或潜在价值的材料及由此产生的遗传信息；依赖遗传资源完成 = 利用了其遗传功能；须在请求书中说明并填写规定表格（细则第29条；法第26条第5款）。

### 7. 外观设计申请文件（细则第30–32条；法第27条）
- 就每件产品需保护的内容交图片或照片；局部外观设计交整体产品视图并用虚实线结合或其他方式标示保护部分；请求保护色彩的交彩色图片或照片（细则第30条）。
- 简要说明写产品名称、用途、设计要点并指定一幅最能表明设计要点的图片或照片；省略视图或请求保护色彩须写明；相似外观设计合案的指定一项基本设计；局部外观设计写明保护部分（视图已用虚实线标明的除外）；禁用商业性宣传用语，不得说明产品性能（细则第31条）。
- 认为必要时可要求交样品或模型：体积不超过30厘米×30厘米×30厘米、重量不超过15公斤；易腐、易损、危险品不得提交（细则第32条）。

### 8. 不丧失新颖性公开的手续（细则第33条；法第24条）
- 中国政府承认的国际展览会 = 依国际展览会公约在国际展览局注册或经其认可的展览会；学术/技术会议 = 国务院有关主管部门或全国性学术团体召开的，以及国务院有关主管部门认可的国际组织召开的会议（细则第33条第1、2款）。
- 法第24条第（二）（三）项情形：申请时声明 + 自申请日起2个月内交已展出/发表及其日期的证明；第（一）（四）项情形：认为必要时可要求在指定期限内交证明；未按规定声明、提交或逾指定期限 → 不适用法第24条（细则第33条第3–5款）。

### 9. 优先权手续（细则第34–38条；法第29、30条）
- 外国优先权副本须经原受理机构证明，依协议经电子交换等途径取得的视为已提交；本国优先权在请求书写明在先申请日与申请号即视为提交副本（细则第34条第1款）。
- 漏写或错写在先申请日、申请号、原受理机构名称中的一项或两项 → 限期补正，逾期视为未要求优先权；申请人名称与在先申请副本不一致 → 须交优先权转让证明，不交视为未要求优先权（细则第34条第2、3款）。
- 外观设计要求外国优先权而在先申请无简要说明的，补交的简要说明不超出在先图片/照片范围即不影响优先权（细则第34条第4款）。
- 可要求一项或多项优先权，多项时期限自最早优先权日起算（细则第35条第1款）。
- 本国优先权类型转换：在先发明或实用新型→可提发明或实用新型，也可就附图显示的设计提外观设计；在先外观设计→外观设计。已要求过外国或本国优先权、已被授予专利权、属于分案申请的在先申请不得作基础（细则第35条第2款）。
- 在先申请自后一申请提出之日起视为撤回；以发明/实用新型申请为基础提出外观设计申请的除外（细则第35条第3款）。
- 超出法第29条期限就相同主题提出发明或实用新型申请，有正当理由的，可在期限届满之日起2个月内请求恢复优先权（细则第36条）。
- 已要求优先权的发明/实用新型申请人，可在优先权日起16个月内或申请日起4个月内请求增加或改正优先权要求（细则第37条）。
- 在中国无经常居所或营业所的申请人申请专利或要求外国优先权，认为必要时须提供国籍证明或注册地证明、所属国承认中国主体同等享有专利权与优先权的证明（细则第38条）。

### 10. 单一性与撤回（细则第39–41条；法第31、32条）
- 发明/实用新型合案：技术上相互关联，包含一个或多个相同或相应的特定技术特征，即每一项发明或实用新型作为整体对现有技术作出贡献的技术特征（细则第39条；法第31条第1款）。
- 同一产品相似外观设计合案：其他设计须与简要说明指定的基本设计相似，且不超过10项；成套产品合案：各产品属分类表同一大类、习惯上同时出售或同时使用、且设计构思相同；两项以上合案的，顺序编号标注在每件产品各幅图片或照片名称之前（细则第40条；法第31条第2款）。
- 撤回申请须提交声明，写明发明创造名称、申请号、申请日；声明在公布印刷准备完成后提出的，申请文件仍公布，撤回声明在以后的专利公报公告（细则第41条；法第32条）。

## 关键概念
- **代表人** — 2人以上申请人未委托代理时，除另有声明外的第一申请人（细则第17条第3款）。
- **必要技术特征** — 独立权利要求为解决技术问题必须记载的特征（细则第23条第2款）。
- **前序部分与特征部分** — 独立权利要求两段：前序写主题及与最接近现有技术共有的特征，特征部分写区别特征（细则第24条第1款）。
- **多项从属权利要求** — 引用两项以上在前权利要求的从属权利要求，须择一引用且不得再被多项从属引用（细则第25条第2款）。
- **摘要附图** — 请求书中指定的最能说明技术特征的一幅附图（细则第26条第2款）。
- **保藏证明与存活证明** — 认可保藏单位出具、申请日起4个月内须交的两份文件（细则第27条第（一）项）。
- **遗传资源** — 取自人体、动物、植物或微生物等、含遗传功能单位并有实际或潜在价值的材料及由此产生的遗传信息（细则第29条第1款）。
- **依赖遗传资源完成的发明创造** — 利用了遗传资源的遗传功能完成的发明创造（细则第29条第1款）。
- **局部外观设计** — 以整体产品视图加虚实线等方式标示保护部分的外观设计（细则第30条第2款）。
- **基本设计** — 相似外观设计合案时简要说明中指定的一项，其他设计须与之相似（细则第31条第2款、第40条第1款）。
- **中国政府承认的国际展览会** — 在国际展览局注册或经其认可的展览会（细则第33条第1款）。
- **特定技术特征** — 每一项发明或实用新型作为整体对现有技术作出贡献的技术特征（细则第39条）。

## 思维模型
- **三对一致性**：名称（请求书↔说明书）、术语（权利要求书↔说明书）、附图标记（文字↔附图）须双向对应，不对齐即形式缺陷（细则第20、21、22条）。
- **优先权三段链**：声明（请求书三要素）→副本（经证明/电子交换/本国视为提交）→主体一致（不一致须转让证明），任一段断裂即视为未要求（细则第19条第（五）项、第34条）。
- **两把时间尺**：自申请日起的4个月（保藏证明、保藏信息补正、增改优先权）与2个月（不丧失新颖性证明、恢复优先权），加自优先权日起的16个月（增改优先权）（细则第27、33、36、37条）。
- **本国优先权是置换**：后一申请提出之日在先申请即视为撤回；已要求过优先权、已授权、分案的不能再作基础（细则第35条）。
- **单一性看贡献**：发明/实用新型看是否共享特定技术特征；外观看是否与基本设计相似或设计构思相同（细则第39、40条）。

## 反模式
- **说明书写"如权利要求1所述的装置"或"业界领先"**：违反引用语与宣传用语禁令（细则第20条第3款）。
- **权利要求中插图或写"如图3所示"**：只允许化学式/数学式，引用附图仅限绝对必要（细则第22条第3款）。
- **"根据权利要求1和2所述"的多项从属，或多项从属再引多项从属**：必须择一、不得多引多（细则第25条第2款）。
- **只保藏样品、不在4个月内交保藏证明和存活证明**：视为未提交保藏（细则第27条第（一）项）。
- **展会/会议公开后申请时未声明，或2个月内未交证明**：不适用法第24条（细则第33条第5款）。
- **申请人名称与在先申请副本不一致却不交转让证明**：视为未要求优先权（细则第34条第3款）。
- **一件申请塞入11项相似外观设计，或简要说明写产品性能**：超10项上限；简要说明禁写性能（细则第40条第1款、第31条第4款）。

## 实例演练
拟例：乙研究所 2025-03-03 在全国性学术团体召开的学术会议上首次发表一株新菌株的发酵方法，2025-04-01 提交发明申请A；公众无法获得该菌株，文字描述不足以实施。
1. 会议公开：请求书须声明，并在 2025-06-01 前交发表及日期证明，否则不适用法第24条（细则第33条）。
2. 生物材料：样品最迟 2025-04-01 保藏；保藏证明和存活证明最迟 2025-08-01 提交；请求书和说明书漏写拉丁文分类命名或保藏单位信息的也须 2025-08-01 前补正，逾期均视为未提交保藏（细则第27条）。利用了菌株的遗传功能→请求书中说明并填表（细则第29条）。
3. 撰写：独立权利要求"一种发酵方法，其特征是……"仅一项且在从属之前；从属写"根据权利要求1或2所述的方法"（择一）；请求书指定摘要附图（细则第24–26条）。
4. 2026-03-20 就相同主题提交改进申请B并要求A的本国优先权（期限至 2026-04-01）：请求书写明A的申请日和申请号即视为交副本；A自 2026-03-20 视为撤回；A若已授权则不能作基础（细则第34条第1款、第35条）。漏写申请号→限期补正，逾期视为未要求（细则第34条第2款）。因正当理由迟于 2026-04-01 提出的，可在 2026-06-01 前请求恢复（细则第36条）；增改优先权要求截至 2026-08-01（优先权日起16个月）或 2026-07-20（B申请日起4个月）（细则第37条）。
5. A公布后丙公司要以实验目的使用该菌株：向国务院专利行政部门提出请求并作不外传、授权前仅作实验的保证（细则第28条）。

## 关键要点
1. 请求书九项、说明书五段带标题、独立权利要求在前从属在后（细则第19、20、24条）。
2. 名称、术语、附图标记三对一致；说明书、权利要求书、摘要禁用引用语、插图和宣传语（细则第20–22、26条）。
3. 多项从属只能择一引用，不得作为另一多项从属的基础（细则第25条）。
4. 生物材料：保藏不晚于申请日/优先权日，证明与信息补正各4个月，逾期视为未提交保藏（细则第27条）。
5. 法第24条第（二）（三）项情形：申请时声明 + 2个月证明，缺一即不适用（细则第33条）。
6. 优先权三要素漏写错写可限期补正，逾期视为未要求；主体不一致须转让证明（细则第34条）。
7. 本国优先权使在先申请视为撤回（外观以发明/实用新型为基础除外）；恢复2个月、增改16个月/4个月（细则第35–37条）。
8. 相似外观设计不超过10项且须与基本设计相似；样品模型不超过30厘米×30厘米×30厘米、15公斤（细则第40、32条）。
