# 专利法 · 第四章 专利申请的审查和批准（第34–41条）

> 来源层：《中华人民共和国专利法》（2020年修正）｜本章 ID：`law-ch04`｜同一主题在另两层的章节见文末「关联」；条文级对照见 [crosswalk.md](../crosswalk.md)

## 核心要点
发明走"初步审查 → 18个月公布 → 申请人请求实质审查 → 审查意见/答复 → 授权或驳回"的早期公开、延迟审查制；实用新型和外观设计只经初步审查即授权。多个"逾期视为撤回"是本章最大的权利陷阱。

## 引入的框架
- **发明的审批时间线（第34、35、39条）**：初步审查合格 → 自申请日起满18个月即行公布（可请求早日公布）→ 申请人自申请日起3年内随时请求实质审查（无正当理由逾期不请求 → 视为撤回；部门认为必要时可自行实审）→ 实审无驳回理由 → 授权决定 + 发证 + 登记 + 公告，专利权自公告之日起生效。
- **实用新型/外观设计的授权（第40条）**：初步审查无驳回理由 → 授权决定 + 发证 + 登记 + 公告，自公告之日起生效。没有实质审查环节。
- **审查意见循环（第37、38条）**：实审认为不符合规定 → 通知申请人在指定期限内陈述意见或修改；无正当理由逾期不答复 → 视为撤回；陈述/修改后仍不符合 → 驳回。
- **参考资料义务（第36条）**：请求实审时应提交申请日前与发明有关的参考资料；已在外国申请的，部门可要求在指定期限内提交该国的检索资料或审查结果；无正当理由逾期不提交 → 视为撤回。
- **驳回后的两级救济（第41条）**：对驳回决定不服 → 收到通知之日起3个月内向国务院专利行政部门请求复审 → 对复审决定不服 → 收到通知之日起3个月内向人民法院起诉。

## 关键概念
- **初步审查**：所有类型都经过的形式与明显缺陷审查。
- **实质审查**：仅发明经过，检验三性等实质条件，须申请人请求。
- **视为撤回**：法律直接推定放弃，本章出现三次（第35、36、37条）。
- **公告之日**：三类专利权统一的生效时点。
- **复审**：起诉前必经的行政内部救济。

## 思维模型
- 把发明审批看成"申请人驱动"的流程：公布可以催、实审必须自己请求、意见必须自己答，部门不会替你推进。
- 把实用新型看作"快但脆"：没有实审就授权，因此稳定性弱，维权时常被要求出具专利权评价报告（第66条）。
- 每个"指定期限"都是悬崖：过期的默认结果是撤回，而非延期。

## 反模式
- **申请日起3年内忘记请求实审**：整个发明申请视为撤回。
- **收到审查意见不答复或迟答复**：视为撤回，复审也救不回来。
- **以为实用新型经过了严格审查**：授权不等于稳定，遇到无效宣告风险高。
- **驳回后直接去法院**：必须先在3个月内请求复审，对复审决定不服才能起诉。

## 实例演练
发明申请日2022-05-10。2023-11-10（满18个月）公布；申请人最迟须在2025-05-10前请求实审。2025-01-15请求实审并提交参考资料。2026-02-01收到审查意见指定4个月内答复 → 须在2026-06-01前陈述意见或修改。若2026-08-01收到驳回决定 → 2026-11-01前请求复审；复审维持驳回、2027-03-01收到通知 → 2027-06-01前向人民法院起诉。

## 关键要点
1. 发明：18个月公布，3年内必须请求实审（第34、35条）。
2. 实用新型/外观设计只有初步审查，授权快但稳定性弱（第40条）。
3. 三个"逾期视为撤回"：不请求实审、不交参考资料、不答复意见（第35–37条）。
4. 专利权自公告之日起生效，不是自决定之日（第39、40条）。
5. 驳回救济路径固定：3个月复审 → 3个月起诉（第41条）。

## 关联
- **第三章**：审查意见多源于说明书/权利要求缺陷；答复时的修改受第33条限制。
- **第五章**：审批延迟可触发第42条的专利权期限补偿。
- **第一章**：第13条临时保护费自公布之日起算，公布时点由本章决定。
