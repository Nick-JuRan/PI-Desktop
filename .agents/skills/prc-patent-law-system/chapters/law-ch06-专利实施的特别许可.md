# 专利法 · 第六章 专利实施的特别许可（第48–63条）

> 来源层：《中华人民共和国专利法》（2020年修正）｜本章 ID：`law-ch06`｜同一主题在另两层的章节见文末「关联」；条文级对照见 [crosswalk.md](../crosswalk.md)

## 核心要点
三种非市场化的许可机制：国家推广应用（第49条）、专利权人自愿的开放许可（第50–52条，2020年新增）、行政部门强制许可（第53–63条）。强制许可有五个法定事由、三个限制和一套程序保障。

## 引入的框架
- **推广应用（第49条）**：国有企业事业单位的发明专利对国家利益或公共利益有重大意义 → 国务院有关主管部门和省级人民政府报经国务院批准 → 在批准范围内推广应用，允许指定单位实施，实施单位按国家规定向专利权人支付使用费。
- **开放许可（第50–52条）**：
  - 成立：专利权人自愿以书面方式向国务院专利行政部门声明愿意许可任何单位或个人实施，并明确许可使用费支付方式、标准 → 部门公告。实用新型/外观设计声明须附专利权评价报告。
  - 取得：任何人书面通知专利权人 + 按公告标准支付使用费 → 即获得实施许可。
  - 效果：开放许可期间专利年费相应减免；专利权人可与被许可人协商后给予普通许可，但不得就该专利给予独占或排他许可。
  - 撤回：书面提出并公告，不影响在先给予的开放许可效力。
  - 纠纷：协商 → 请求国务院专利行政部门调解，或向人民法院起诉。
- **强制许可的五个事由（第53–56条）**（仅适用于发明和实用新型）：
  1. 不实施/未充分实施：自授权日起满3年，且自申请日起满4年，无正当理由（第53条第(一)项）。
  2. 反垄断：行使专利权的行为被依法认定为垄断行为，为消除或减少其对竞争的不利影响（第53条第(二)项）。
  3. 紧急状态、非常情况或公共利益目的（第54条）。
  4. 公共健康：对取得专利权的药品，给予制造并出口到符合国际条约规定的国家或地区的强制许可（第55条）。
  5. 从属专利：后一专利比前一专利具有显著经济意义的重大技术进步，且其实施有赖于前一专利 → 可给予实施前一专利的强制许可；前一专利权人也可申请实施后一专利的交叉强制许可（第56条）。
- **强制许可的三个限制（第57–59条）**：半导体技术仅限公共利益目的和反垄断情形（第57条）；除反垄断和公共健康出口外，实施应主要为供应国内市场（第58条）；依第53条第(一)项和第56条申请的，须证明曾以合理条件请求许可但在合理时间内未获得（第59条）。
- **程序与救济（第60–63条）**：决定及时通知专利权人并登记公告；决定应根据理由规定实施范围和时间，理由消除且不再发生 → 应专利权人请求经审查终止；被许可人无独占实施权且无权允许他人实施；应支付合理使用费，协商不成由国务院专利行政部门裁决；对强制许可决定或使用费裁决不服 → 收到通知之日起3个月内向人民法院起诉。

## 关键概念
- **普通许可 / 独占许可 / 排他许可**：开放许可下只能叠加普通许可。
- **专利权评价报告**：实用新型/外观设计进入开放许可的门票，也是第66条侵权程序中的证据。
- **合理条件 + 合理时间**：申请不实施型和从属型强制许可的前置谈判义务。
- **主要为供应国内市场**：强制许可的地域导向限制。

## 思维模型
- 把三种机制排成"自愿程度递减"：推广应用（国家决定、国企专利）→ 开放许可（权利人自愿、面向所有人）→ 强制许可（违背权利人意愿、需法定事由）。
- 开放许可 = "标价挂牌"：定价公开、付款即得、不排他，换来年费减免和交易成本降低。
- 强制许可门槛设计为"先谈再强制"：除公共利益类事由外都要证明谈判失败。

## 反模式
- **实用新型直接声明开放许可而不附评价报告**：不符合第50条要件。
- **开放许可期间另签独占许可**：明确禁止。
- **主张"对方不实施"就申请强制许可**：还需满足授权满3年且申请满4年、无正当理由、且已合理请求许可未果。
- **取得强制许可后转授他人**：被许可人无权允许他人实施。

## 实例演练
甲公司持有一项2019-01授权（2015-06申请）的发明专利，一直未实施也无正当理由。乙公司2023年想实施：先以合理条件书面请求许可（第59条）；若合理时间内未获许可，因已满"授权满3年（2022-01）且申请满4年（2019-06）"，可依第53条第(一)项申请强制许可。获准后乙不得独占、不得转授（第61条），使用费协商不成由部门裁决（第62条），且实施主要面向国内市场（第58条）。反过来，若甲愿意授权所有人，可声明开放许可并公告费率，乙付费即取得许可，甲同时享受年费减免（第50、51条）。

## 关键要点
1. 开放许可：书面声明 + 公告费率 + 付费即得 + 不得独占/排他（第50–51条）。
2. 强制许可只针对发明和实用新型，五个事由各有不同门槛（第53–56条）。
3. 不实施型的时间门槛是"授权满3年 且 申请满4年"（第53条第(一)项）。
4. 半导体、国内市场、先行谈判是三道限制（第57–59条）。
5. 被强制许可方不独占、不能转授、要付合理费用，争议3个月内起诉（第61–63条）。
