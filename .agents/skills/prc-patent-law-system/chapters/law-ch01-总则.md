# 专利法 · 第一章 总则（第1–21条）

> 来源层：《中华人民共和国专利法》（2020年修正）｜本章 ID：`law-ch01`｜同一主题在另两层的章节见文末「关联」；条文级对照见 [crosswalk.md](../crosswalk.md)

## 核心要点
界定专利法保护的三类"发明创造"，规定权利归谁（职务/合作/委托）、专利权禁止他人做什么（第11条），以及申请与行权的三条底线：先申请、诚实信用、向外国申请前先保密审查。

## 引入的框架
- **三类发明创造（第2条）**：发明 = 对产品、方法或其改进提出的新的技术方案；实用新型 = 对产品的形状、构造或其结合提出的适于实用的新的技术方案；外观设计 = 对产品整体或局部的形状、图案或其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。
  - 何时用：决定申请哪种专利。
  - 判断：涉及"方法"→只能是发明；只涉及产品形状/构造→可选实用新型；卖点是外观美感→外观设计（2020年新增"局部"外观设计）。
- **职务发明创造归属（第6条）**：执行本单位任务，或主要利用本单位物质技术条件完成 → 申请权归单位，批准后单位为专利权人；非职务 → 归发明人/设计人；仅"利用单位物质技术条件"且单位与个人有合同约定 → 从约定。任何单位或个人不得压制非职务发明的申请（第7条）。
- **合作/委托完成（第8条）**：除另有协议外，归完成或共同完成的一方。
- **先申请 + 禁止重复授权（第9条）**：同样的发明创造只授一项专利权；多人分别申请 → 授予最先申请的人。唯一例外：同一申请人同日既申请实用新型又申请发明，先获得的实用新型尚未终止且申请人声明放弃 → 可授予发明专利权。
- **专利权的排他内容（第11条）**：发明/实用新型 → 未经许可不得为生产经营目的制造、使用、许诺销售、销售、进口专利产品，或使用专利方法及使用、许诺销售、销售、进口依该方法直接获得的产品。外观设计 → 制造、许诺销售、销售、进口（不含"使用"）。
- **转让生效要件（第10条）**：书面合同 + 向国务院专利行政部门登记并公告，自登记之日起生效；向外国人/外国企业/外国组织转让须依法办理手续。
- **共有权利行使（第14条）**：有约定从约定；无约定 → 共有人可单独实施，或以普通许可方式许可他人（使用费在共有人之间分配）；其他任何行使方式须全体共有人同意。
- **向外国申请的保密审查（第19条）**：在中国完成的发明或实用新型向外国申请专利 → 事先报经国务院专利行政部门保密审查；专利国际申请同样适用。违反者在中国申请不授予专利权；泄露国家秘密另受处分/刑责（第78条）。
- **诚实信用与禁止滥用（第20条）**：申请专利和行使专利权应遵循诚信原则；滥用专利权排除或限制竞争、构成垄断 → 依反垄断法处理。

## 关键概念
- **临时保护费（第13条）**：发明专利申请公布后、授权前，申请人可要求实施者支付适当费用。
- **实施许可合同（第12条）**：实施他人专利须订立许可合同并付费；被许可人无权允许合同外的第三人实施。
- **职务发明奖励与报酬（第15条）**：单位应给予奖励；实施后按推广应用范围和经济效益给予合理报酬；国家鼓励以股权、期权、分红等产权激励方式分享收益。
- **署名权与标识权（第16条）**：发明人/设计人有权在专利文件中署名；专利权人有权在产品或包装上标专利标识。
- **涉外代理（第17、18条）**：在中国无经常居所或营业所的外国主体依协议/条约/互惠原则申请，且应当委托依法设立的专利代理机构；中国主体可以委托。代理机构对未公布/公告内容负保密义务。
- **不授权与保密（第4、5条）**：涉及国家安全或重大利益需保密的按国家规定办理；违反法律、社会公德或妨害公共利益的发明创造，以及违法获取/利用遗传资源并依赖其完成的发明创造，不授予专利权。
- **管理体制（第3、21条）**：国务院专利行政部门统一受理和审查、依法授权；省级管理专利工作的部门管本行政区域；行政部门须客观、公正、准确、及时，并建设专利信息公共服务体系，公布/公告前负保密义务。

## 思维模型
- 把第11条当作"侵权行为清单"：判断某行为是否落入专利权，先看它是不是清单里的动词 + 是否"为生产经营目的"。
- 把归属问题当作"任务 → 资源 → 合同"三步：先问是否执行单位任务，再问是否主要用单位资源，最后看有没有约定。
- 把"申请日"看作一切竞争的裁判尺：先申请原则、新颖性、优先权、先用权都以它为锚点。

## 反模式
- **把方法申请为实用新型**：实用新型只保护产品的形状/构造，方法方案会被拒。
- **未经保密审查直接向外国申请**：在中国的同一发明将不被授权，还可能承担泄密责任。
- **专利转让只签合同不登记**：转让自登记之日起才生效。
- **共有专利一方擅自给独占许可**：无约定时只能单独实施或给普通许可。
- **把"使用"外观设计产品当侵权起诉**：外观设计的排他权不含使用。

## 实例演练
工程师甲在下班后用自家设备完成一项改进，但该改进正是公司安排给他的研发课题 → 属于"执行本单位的任务"→ 职务发明，申请权归公司（第6条第1款）。若该改进与其工作任务无关，但主要使用了公司实验室设备，且劳动合同约定此类成果归甲 → 从约定（第6条第3款）。公司若想对外转让该专利，须签书面合同并登记公告后才生效（第10条）。

## 关键要点
1. 先想清楚客体类型（第2条），再决定申请路线。
2. 权利归属先看"任务/资源"，合同可以改写默认规则（第6、8条）。
3. 同样的发明创造只授一项专利，比的是申请日（第9条）。
4. 涉外申请两条硬规矩：外国人必须委托代理机构（第18条），中国完成的发明先保密审查（第19条）。
5. 转让登记生效、共有需全体同意，是最常被忽略的形式要件（第10、14条）。

## 关联
