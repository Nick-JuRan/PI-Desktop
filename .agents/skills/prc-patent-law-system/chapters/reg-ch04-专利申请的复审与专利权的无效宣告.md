# 实施细则 · 第四章 专利申请的复审与专利权的无效宣告（第65–76条）

> 来源层：《中华人民共和国专利法实施细则》（2023年修订）｜本章 ID：`reg-ch04`｜同一主题在另两层的章节见文末「关联」；条文级对照见 [crosswalk.md](../crosswalk.md)

## 核心要点
复审只针对驳回决定指出的缺陷，出口只有驳回复审请求或撤销驳回两种；无效宣告要求请求人理由与证据逐项对应、1个月内锁定，专利权人只能缩小权利要求，指定期限不得延长，撤回也不一定终止程序。

## 引入的框架

### 一、复审请求的提出与受理（第65条）
- 复审须以复审请求书提出并说明理由，必要时附证据（细则第65条第1款；法第41条）。
- 不符合法第18条第1款（外国主体资格）或法第41条第1款（收到驳回通知后3个月内提出）→ 不予受理，书面通知并说明理由（细则第65条第2款）。
- 请求书格式不合规 → 指定期限内补正；期满未补正 → 视为未提出（细则第65条第3款）。

### 二、复审阶段的修改边界（第66条）
- 修改时机仅两个：提出复审请求时、答复复审通知书时（细则第66条）。
- 修改仅限于消除驳回决定或复审通知书指出的缺陷，无关修改不被允许（细则第66条）。

### 三、复审的审理路径与两种结果（第67、68条）
- 复审认为请求不合规，或申请有其他明显违法情形（不限于原驳回理由）→ 发复审通知书，限期陈述意见（细则第67条第1款）。
- 期满未答复 → 视为撤回；陈述或修改后仍不合规 → 作出驳回复审请求的复审决定（细则第67条第1款）。
- 原驳回决定不合规，或修改后已消除指出的缺陷 → 撤销原驳回决定、继续审查程序（细则第67条第2款）。
- 决定作出前可撤回复审请求，撤回后复审程序终止（细则第68条）。

### 四、无效宣告请求的形式与法定理由（第69条）
- 请求无效或部分无效须提交无效宣告请求书和必要证据，一式两份（细则第69条第1款；法第45条）。
- 请求书须结合全部证据具体说明理由，并指明每项理由所依据的证据（细则第69条第1款）。
- 无效理由为封闭清单（细则第69条第2款）：
  - 法第2条（发明创造定义）、第22条（三性）、第23条（外观设计授权条件）、第25条（不授权客体）、第5条（违法、公德、公共利益、遗传资源）；
  - 法第26条第3款（充分公开）、第26条第4款（权利要求得到支持、清楚简要）、第27条第2款（外观设计图片照片清楚显示）、第33条（修改超范围）、细则第49条第1款（分案超范围）、细则第23条第2款（独立权利要求缺少必要技术特征）；
  - 法第19条第1款（未经保密审查向外国申请）、第9条（同样的发明创造只授一项）、细则第11条（诚实信用原则，2023年新增）。

### 五、不予受理、补正与1个月补充期（第70、71条）
- 不符合法第18条第1款或细则第69条 → 不予受理（细则第70条第1款）。
- 一事不再理：决定作出后再以同样的理由和证据请求 → 不予受理；换理由或换证据不受此限（细则第70条第2款）。
- 以法第23条第3款（权利冲突）请求外观设计无效却未提交证明权利冲突的证据 → 不予受理（细则第70条第3款）。
- 请求书格式不合规 → 指定期限内补正；期满未补正 → 视为未提出（细则第70条第4款）。
- 受理后，请求人可在提出请求之日起1个月内增加理由或补充证据；逾期可以不予考虑（裁量）（细则第71条）。

### 六、双方答复与专利权人的修改空间（第72、73条）
- 请求书及有关文件副本送交专利权人，指定期限陈述意见（细则第72条第1款）。
- 双方应限期答复转送文件通知书或无效宣告请求审查通知书；未答复不影响审理，与复审的视为撤回不同（细则第72条第2款）。
- 发明、实用新型专利权人可修改权利要求书，但不得扩大原专利保护范围；在修改后权利要求基础上维持有效或部分无效的，公告修改后的权利要求（细则第73条第1款）。
- 发明、实用新型不得改说明书和附图；外观设计不得改图片、照片和简要说明，即毫无修改空间（细则第73条第2款）。

### 七、口头审理、期限刚性与撤回（第74–76条）
- 口审由专利行政部门依当事人请求或案情需要决定，非一经请求必开（细则第74条第1款）。
- 决定口审 → 发口头审理通知书告知日期、地点；当事人应限期答复（细则第74条第2款）。
- 请求人未答复且不参加口审（两条件并存）→ 视为撤回；专利权人不参加 → 可缺席审理（细则第74条第3款）。
- 无效审查程序中的指定期限一律不得延长（细则第75条）。
- 决定前请求人可撤回；撤回或视为撤回 → 程序终止，但已进行的审查工作足以作出无效或部分无效决定的，不终止（细则第76条）。

## 关键概念
- **复审请求书** — 启动复审的法定文件，须载明理由，必要时附证据（细则第65条第1款）。
- **视为未提出** — 请求书格式不合规且期满未补正的后果（细则第65条第3款、第70条第4款）。
- **视为撤回** — 复审中未答复复审通知书，或无效中请求人不答复口审通知且不到场的后果（细则第67条第1款、第74条第3款）。
- **撤销原驳回决定、继续审查** — 复审的肯定性结果，回到审查程序而非直接授权（细则第67条第2款）。
- **无效宣告请求的理由** — 法定封闭清单，请求只能援引其中条款（细则第69条第2款）。
- **一事不再理** — 决定作出后以同样理由和证据再请求的不予受理规则（细则第70条第2款）。
- **1个月补充期** — 自提出无效请求之日起可增加理由、补充证据的窗口（细则第71条）。
- **不得扩大原专利的保护范围** — 无效中修改权利要求的唯一实体边界（细则第73条第1款）。

## 思维模型
- **复审是靶向纠错，不是重新审查**：修改只对准指出的缺陷，结论只有驳回复审请求或撤销驳回、继续审查（细则第66、67条）。
- **无效是"请求人先定框，专利权人只能收缩"**：理由与证据1个月内锁定，专利权人仅能在不扩大范围内改权利要求（细则第69、71、73条）。
- **缺席的后果不对称**：请求人不答复口审通知又不到场 → 视为撤回；专利权人不到场 → 缺席审理；一般通知未答复不影响审理（细则第72、74条）。
- **无效是硬期限、半公益程序**：指定期限不得延长，撤回也挡不住已成熟的无效结论（细则第75、76条）。

## 反模式
- **借复审重写申请文件**：修改与驳回理由无关（细则第66条）。
- **无效请求书只罗列条款不对应证据**：违反细则第69条第1款，依第70条第1款不予受理。
- **以权利冲突为由却不附证据**：外观设计无效专门不受理情形（细则第70条第3款）。
- **打算"边审边补"证据**：超过1个月可被不予考虑，且指定期限无法延长（细则第71、75条）。
- **和解后靠撤回无效请求"救"对方专利**：审查工作已足以宣告无效的，程序不终止（细则第76条第2款）。

## 实例演练
拟例：甲的发明申请因缺乏创造性被驳回，甲提出复审并合并权利要求1与3（细则第66条）；复审通知书另指出权利要求2不清楚，甲限期删除，缺陷消除后撤销驳回、继续审查（细则第67条），随后授权。
乙于2024-03-01提出无效请求，请求书与证据1、2一式两份，逐项写明"法第22条第3款→证据1+2""法第26条第4款→证据2"（细则第69条第1款）。03-20乙补充证据3并增加法第26条第3款理由，在1个月内应予考虑；05-10再补证据4，逾期，可以不予考虑（细则第71条）。甲收到转送文件通知书后未答复，审理照常（细则第72条第2款）。甲限缩权利要求1、未动说明书（细则第73条）；请求延长口审答复期被拒（细则第75条）。若乙既不答复口审通知又不到场，请求视为撤回，但已能认定权利要求1无效的，程序不终止（细则第74条第3款、第76条第2款）。最终在修改后权利要求基础上宣告部分无效并公告该权利要求（细则第73条第1款）；乙以同样理由和证据再请求 → 不予受理（细则第70条第2款）。

## 关键要点
1. 复审：请求书+理由（+证据）；格式未补正视为未提出；主体或期限不符则不予受理（细则第65条）。
2. 复审修改只能消除指出的缺陷；不答复复审通知书即视为撤回；结果只有驳回复审请求或撤销驳回继续审查，决定前可撤回（细则第66–68条）。
3. 无效请求书须"理由—证据"逐项对应、一式两份，理由限于法定清单（细则第69条）。
4. 四类不予受理：主体或形式不符、同样理由和证据再请求、权利冲突无证据、格式未补正（细则第70条）。
5. 1个月内补充理由和证据，逾期可不予考虑；指定期限一律不得延长（细则第71、75条）。
6. 专利权人只能缩小权利要求；请求人缺席口审视为撤回，专利权人缺席则缺席审理；撤回不阻止已成熟的无效决定（细则第73、74、76条）。
