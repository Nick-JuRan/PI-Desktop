# patent-presearch

引导主代理按顺序完成指定专利权利要求的分类和关键词扩展：先调用 `patent-classifier`，确认其完成后，再调用 `patent-keyworder`。

## 输入

用户提供一个申请文件夹，目录结构包含：

```text
<发明名称>/
├── 申请文件/
│   ├── 基本信息.md
│   ├── 权利要求书.md
│   └── 说明书.md
└── 理解发明/
    ├── 权1.md
    ├── 权2.md
    └── 权x.md
```

用户会指定待处理的权利要求编号；未指定时使用权利要求 1。主代理确定申请文件夹和目标权利要求后，只向子代理传递该任务所需的 `说明书.md` 与对应的 `理解发明/权x.md`。

## 委派顺序

1. 启动 `patent-classifier`，传入目标权利要求对应的 `说明书.md` 和 `权x.md`，要求其按自身提示词完成分类并原地更新 `权x.md`。
2. 等待 `patent-classifier` 的回执，核对其状态和目标文件路径。只有分类阶段已完成并且目标文件仍可读取时，才能进入下一步；失败或未完成时保留回执并结束流程，不提前调用关键词代理。
3. 读取分类代理完成后的最新文件状态，将最新的 `说明书.md` 和 `权x.md` 传给 `patent-keyworder`。不得把分类前的旧文件内容作为第二阶段输入。
4. 等待 `patent-keyworder` 的回执，核对目标 `权x.md` 已完成更新。关键词代理结束后，宣告本 Skill 流程结束。

## 输出与回执

两个子代理都在同一个 `权x.md` 上原地更新：分类代理先写入分类结果，关键词代理随后补充关键词。主代理不得另建替代报告或覆盖任一子代理的文件。

主代理必须保留两个子代理的原始回执，并在最终反馈中报告：分类阶段状态、关键词阶段状态、目标权利要求文件路径，以及任一阶段返回的缺失或未完成信息。具体分类格式、关键词数量和字段填写规则以各自子代理提示词为准，本 Skill 不重复规定。
